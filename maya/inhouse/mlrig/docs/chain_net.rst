並ぶチェーンの受け渡し(ChainNet)
=================================

``mlrig.setups.ChainNet`` は、2本(または1本)の親チェーンのFKの動きを、その間に並ぶ子チェーンへ割合に応じて
受け渡します。羽・ひれ・触手の束・スカートの板・髪の房のように同じ形のチェーンが並ぶ部位で、
両端の親チェーンだけを動かせば間のチェーンが付いてくる仕組みを、少ないコントロールで作るための部品です。
子チェーンの節は自分のコントロールとして手付けでき、親から受け取った動きの上に重なります。
Maya標準ノード( ``multMatrix`` ・ ``blendMatrix``)のみで構築し、独自プラグインやフレームごとのPythonは使いません。

.. code-block:: python

   from mlrig.setups import ChainNet

   graph = ChainNet.create(
       ["finA_0", "finA_1", "finA_2"],          # 親チェーンA
       ["finB_0", "finB_1", "finB_2"],          # 親チェーンB
       [["fin1_0", "fin1_1", "fin1_2"],         # 間の子チェーン
        ["fin2_0", "fin2_1", "fin2_2"]],
       name="finNet", connect=True)
   graph.container.getPlug("bias0").set(0.3)    # 1本目の子チェーンはBの動きを30%使う

引数
----

* ``masterA``: 親チェーンAの節(根元から先の順)。FKのコントロールまたはjoint。
* ``masterB``: 親チェーンBの節。 ``None`` なら動かないチェーンとして扱い、 ``bias`` はAの動きを弱める割合になります。
* ``slaves``: 子チェーンの列。各チェーンは根元から先の順の節。節の数はチェーンごとに違ってよく、
  親より長い子チェーンの節は、親の最後の節の動きを使います。
* ``name``: 一意なcontainer名。
* ``biases``: 子チェーンごとの、Bの動きを使う割合(0〜1)。省略時は、Bがあるとき等間隔 ``(k+1)/(n+1)`` 、
  Bが無いとき0。後からcontainerの ``bias<番号>`` で変更・キー設定できます。
* ``connect``: ``True`` なら各節の ``offsetParentMatrix`` へ ``matrix<k>_<j>`` を接続します。
  その節の ``offsetParentMatrix`` は未接続であること(値は生成時のものを取り込みます)。

出力(containerのアトリビュート)
---------------------------------

* ``bias<k>``: 子チェーンkの、Bの動きを使う割合(keyable)。
* ``delta<k>_<j>``: 子チェーンkの節jが受け取る、親の差を補間した行列。
* ``matrix<k>_<j>``: 子チェーンkの節jの ``offsetParentMatrix`` に使う行列。

計算
----

行ベクトル規約で、節のローカル行列( ``matrix`` 、jointはjointOrientを含む)を ``M`` 、生成時の値を ``M0`` とします。

1. 親の各節の差 ``D = M * M0^-1`` (節の生成時のローカル空間での変化)を ``multMatrix`` で求めます。
2. 子チェーンkの節jは、親の同じ番号の節の差 ``D_A`` ・ ``D_B`` を ``blendMatrix`` で
   ``D = blend(D_A, D_B, bias_k)`` にします(位置・scaleは線形補間、回転はクォータニオンの球面線形補間)。
3. ``matrix<k>_<j> = S0^-1 * D * S0 * O0`` ( ``S0`` ・ ``O0`` は子の節の生成時の ``matrix`` ・ ``offsetParentMatrix``)。

子の節のワールド行列は ``S * S0^-1 * D * S0 * O0 * 親`` になります。子の節の生成時のローカル空間で親の差を加え、
その上に子自身の手付けの差 ``S * S0^-1`` が重なります。差を節ごとの生成時のローカル空間で扱うので、
jointOrientや生成時の回転が節ごとに違っても、親の節が「自分の軸で曲がった」分だけ子の節も自分の軸で曲がります。
生成時は差が単位行列なので、作成時に姿勢が跳ねません。

参考にした考え方
----------------

* mGear(``maya/external/mgear5`` 、MITライセンス)の ``chain_net_01`` 部品: 子のチェーンのFKコントロールの上に
  2段の入力のtransformを置き、2本の親(master)チェーンの同じ番号のコントロールの回転・位置のチャンネルに
  ``bias`` と ``1 - bias`` を掛けて足す考え方(親が短いときは最後の節を使う)。
  ここではチャンネルの値の和の代わりに、節ごとの生成時からの差の行列を ``blendMatrix`` で補間し、
  子の節の ``offsetParentMatrix`` へ入れます(コードは流用していません)。

制限
----

* 子の節は番号で親の節に対応させます(チェーン上の長さの割合では対応させません)。
* 親の差が互いに180度に近いと、回転の補間の向きが不定になります。
* 親チェーンの根元の位置の移動(親の外側の空間の変化)は差に含みません。親チェーンと子チェーンは同じ親の空間に
  置き、全体はその親で動かします。
* 子チェーンの間で互いにめり込まないようにする仕組みはありません。
