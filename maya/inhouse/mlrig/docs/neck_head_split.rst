首と頭への回転の分配(NeckHeadSplit)
====================================

``mlrig.setups.NeckHeadSplit`` は、1つの頭のコントロールの回転を **首の関節へ割合で分け**、
**頭はコントロールと同じ向き** にします。アニメーターは頭のコントロールだけを回せばよく、首は根元から
少しずつ曲がってしなり、頭の向きはコントロールの向きのまま変わりません。

* 首のFKコントロールを1つずつ回さずに、頭の向きから首の形を自動で作りたいとき。
* 首の各関節がどれだけ曲がるか(根元を固く、上を柔らかく、など)を割合で調整したいとき。
* 首の割合を減らしても増やしても、頭の向きはコントロールに合わせたいとき。

Maya標準ノード(``multMatrix`` ・ ``pickMatrix`` ・ ``blendMatrix``)だけで組み、各関節のワールド行列を
containerの ``matrix<i>`` に出力します。独自プラグイン、エクスプレッション、フレームごとのPythonは使いません。
生成したノードはcontainerが所有し、作成直後の出力は各関節のワールド行列と一致します(跳ねません)。

.. code-block:: python

   from mlrig.setups import NeckHeadSplit

   split = NeckHeadSplit.create("chest_jnt", ["neck0_jnt", "neck1_jnt", "neck2_jnt", "head_jnt"], "head_ctrl",
                                name="neckSplit", weights=[0.15, 0.25, 0.3])
   cmds.connectAttr("neckSplit.matrix0", "neck0_out.offsetParentMatrix")  # ワールドの親の下の受け側joint
   cmds.setAttr("neckSplit.weight0", 0.1)                                   # 首の根元を固くする

式
--

行列は行ベクトルの書き方(Mayaと同じ、左から右へ掛ける)です。 ``C`` を胸のワールド行列、 ``H`` を頭の
コントロールのワールド行列、 ``H0`` ・ ``C0`` をその作成時の値とします。胸の空間でのコントロールの回転の変化

``D = 回転だけ( (H0 · C0^-1)^-1 · H · C^-1 )``

を ``multMatrix`` と ``pickMatrix`` (移動・スケール・剪断を使わない)で求めます。首の関節 i
(根元から 0, 1, …)について、 ``b_i`` を胸の空間での作成時の骨(一つ前の関節からの差。0番目は胸からの位置)、
``w_i`` を ``weight<i>`` として、仮想の階層

``V_i = slerp(I, D, w_i) · T(b_i) · V_(i-1)`` (``V_-1`` は単位行列)

を根元から積み重ねます。 ``slerp(I, D, w)`` は ``blendMatrix`` で単位行列と ``D`` をクォータニオンで補間した
``D`` の ``w`` 乗の回転です。どれも同じ回転軸の ``D`` の累乗なので、i番目の関節の向きは ``D^(w_0+…+w_i)`` 、
骨は一つ前までの割合の回転で回ります。頭は、位置だけを ``T(b_head) · V_(n-2)`` から取り(``pickMatrix``)、
向きは ``D`` そのものにします。出力は

* 首: ``matrix<i> = O_i · V_i · C``
* 頭: ``matrix<n-1> = O_head · D · T(頭の位置) · C``

で、 ``O_i`` は作成時の胸の空間での行列から位置を除いたもの(関節の向き・スケール)です。作成時は ``D`` が
単位行列なので、出力は作成時のワールド行列と一致します。

首の割合の合計が1より小さいと、残りは頭の首に対する回転になります。合計がちょうど1なら首の先が ``D`` まで回り、
頭は首との作成時の関係を保ちます。1を超えると頭が首に対して逆へ戻り、それでもコントロールの向きを保ちます。

containerのアトリビュート
-------------------------

.. list-table::
   :header-rows: 1

   * - 名前
     - 内容
   * - ``weight0`` 〜 ``weight<n-2>``
     - 首の関節ごとの割合(keyable、0〜1)。既定は各 1/(関節の数、頭を含む)。
   * - ``matrix0`` 〜 ``matrix<n-1>``
     - 首の関節と頭のワールド行列(出力)。ワールドの親の下の、TRSが単位の受け側jointの ``offsetParentMatrix`` へつなぐ。
       ``getOutputs()`` が根元から頭の順で返します。

制限
----

* 分配するのは回転だけです。コントロールの移動は頭の位置に使いません(頭の位置は首の先から決まります)。
* ``D`` の補間はクォータニオンの最短の向きなので、作成時から180度に近い回転では首の曲がる向きが反転します。
* 胸・コントロールのスケールと剪断は扱いません(``pickMatrix`` で回転だけを取り出します)。
* 首の関節は作成時の位置から骨の向きと長さを固定します。作成後に関節の位置を変えた場合は作り直します。
* blendMatrix のクォータニオンの補間と試験側の軸・角度の累乗の差は、行列の成分で最大 1.4e-8 程度です(試験の許容は 1e-6)。

試験
----

``mlrig/__tests__/test_setup_neck_head_split.py`` (``setups`` スイート)で、回転・移動した胸の下の首の3関節と
頭について、作成直後に出力が関節と一致すること、乱数のコントロールの回転・移動と割合の30組で出力が試験側で独立に
書いた式(クォータニオンの軸と角度から作る累乗)と一致すること、頭の回転の変化がコントロールのワールドの回転の変化と
一致し骨の長さが変わらないこと、割合が0と合計1の場合、コントロールが胸と一緒に動くと首と頭が胸に付いていくこと、
container所有とUndo/Redo、引数を確認します。
