NURBS面の再分割を比較する
============================================================

HTools > rigging > knotRangePreview

#. NURBSサーフェスを1つ選択します。Uniform spans U / Vに分割数、Guide U / Vに元のノット範囲内の評価位置を入力します。

#. Compare uniform surface subdivisionを押します。surfaceCmとboundaryCmはサンプル上での面全体・境界の最大位置差、normalDegreesは最大法線差、guideCmは指定UVの位置差です。元の面と履歴を保持したまま比較できます。

#. ノット範囲だけを変える場合は、上部の範囲欄に値を入れてPreview on geometry copyを押します。
