duplicateAndCopySkinWeights
===========================

スキンを付けたメッシュを複製し、同じジョイントでバインドし直してスキンウェイトをコピーするツールです。
複製の表示(visibility)を元につなぎ、\ ``prv_`` の付いたマテリアルがあれば複製に割り当てます。
確認用・別の設定用の「同じように変形するメッシュ」を作るときに使います。

開き方
------

HTools > rigging > duplicateAndCopySkinWeights。

画面
----

画面はありません。選ぶとすぐに処理します。

使い方
------

1. スキンを付けたメッシュ(transform またはシェイプ)を選びます(複数可)。
2. メニューから選びます。メッシュごとに次の処理をします。

   - 複製して ``prv_<元の名前>`` にします(例: ``arm_geo`` → ``prv_arm_geo``)。
   - 元の transform の visibility を、複製の visibility へつなぎます(元を隠すと複製も隠れます)。
   - 元に割り当てたマテリアル ``M`` について、\ ``prv_M`` という名前のマテリアルがシーンにあれば、
     複製の同じ面へ ``prv_M`` を割り当てます(シェーディンググループが無ければ作ります)。無ければ元のマテリアルのままです。
   - 元の skinCluster と同じインフルエンスで複製をバインドし(``skinCluster_prv_<元の名前>``)、
     最大インフルエンス数・その維持(maintainMaxInfluences)・正規化の設定を合わせます。
   - 元のウェイトをコピーします(面の対応は最も近い点、インフルエンスの対応は名前 → 最も近いジョイント → 1対1の順)。

3. 作った複製が選択され、Script Editor に ``Created: [...]`` と出ます。

   :header-rows: 1
   :widths: 30 70

   * - アウトライナー
     - 複製の変形(元のシェイプを隠して表示)
   * - .. image:: ../_static/images/rigging/duplicateAndCopySkinWeights_outliner.png
          :alt: アウトライナー。arm_geo の下に複製の prv_arm_geo ができて選択されている
     - .. image:: ../_static/images/rigging/duplicateAndCopySkinWeights_result.png
          :alt: 肘を曲げたときの複製。prv_body_mat のオレンジ色で、元と同じように曲がっている

上の例では、灰色の ``body_mat`` を割り当てた ``arm_geo`` に対し、シーンにオレンジ色の ``prv_body_mat`` を用意して実行しました。
複製はオレンジ色になり、肘を曲げると元と同じ形に変形します(複製は元と同じ位置に重なってできます)。

注意・制限
----------

- メッシュ以外は ``Skip: ... is not a mesh.``\ 、スキンが無いメッシュは ``Skip: ... is not skinned.`` の警告を出して飛ばします。
  何も選んでいない(メッシュが無い)ときはエラー ``Select skinned meshes.`` になります。
- 全メッシュの処理を1回の Undo で戻せます。
- 複製は実行したときの見た目の形と関節の姿勢でバインドします。ポーズを付けた状態で実行すると、
  バインドポーズへ戻したときに元と形が一致しません。バインドポーズで実行してください。
- 名前の末尾に ``1`` が付いた場合は外そうとします。このため、元の名前が ``1`` で終わる場合(``body1`` など)は、複製の名前から ``1`` が外れます(``prv_body``)。
- スクリプトからは ``duplicate_and_copy_skin_weights(prefix="prv_")`` で接頭辞を変えられます(複製の名前と、探すマテリアルの名前の両方に使います)。
