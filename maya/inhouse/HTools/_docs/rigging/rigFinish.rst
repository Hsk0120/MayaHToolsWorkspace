書き出し用の複製に仕上げ規則を適用する
============================================================

HTools > rigging > rigFinish

#. 書き出す枝のルートTransformを1つ選び、Ruleから適用する仕上げ規則を選びます。Auto Keyをオフ、Undoをオンにします。

#. Preview export duplicate cleanupで対象属性、未使用の中間形状、メッシュの材質を確認します。

#. Create cleaned export duplicateを押します。ルート名に_exportが付いた複製に規則が適用され、事前表示した未使用中間形状が除去されます。元の枝と材質を保持し、Undoを1回実行すると複製を取り消せます。
