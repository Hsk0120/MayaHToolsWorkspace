表示形状と中間形状の改名候補を確認する
============================================================

HTools > rigging > renamePreview

#. 対象のTransformまたはShapeを選択し、Preview selected shapes by purposeを押します。通常の形状には親名＋Shape、中間形状には親名＋ShapeOrigが提示されます。

#. 一覧の元パスと候補名を確認し、変更する行だけを選択してRename selected preview rowsを押します。衝突・参照・ロック・インスタンス・変更不要の印が付いた行は適用対象から外します。

#. Undoを1回実行すると、同時に適用した改名が戻ります。文字列置換の影響だけを調べたい場合は上部のFindとReplace withを使います。
