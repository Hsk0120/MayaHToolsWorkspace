skinWeightKit
=============

メインウィンドウの右端に縦にドックする、スキンのウェイト作業用のパネル Skin Weight Kit の表示・非表示を切り替えます。
本体は Skin Weight Kit のパッケージ(``skinWeightKit``)で、このメニュー項目はその入口です。
``SkinWeightKit.mod`` が有効なら、前回表示していた場合だけ Maya の起動後に自動で表示します。

開き方
------

HTools > rigging > skinWeightKit。スクリプトからは ``import skinWeightKit; skinWeightKit.toggle()`` で切り替えられます。

対象
----

頂点・エッジ・フェースを選ぶとその頂点を、メッシュを選ぶとメッシュ全体を対象にします。パネルの先頭に、対象のメッシュ・
skinCluster・選んだ頂点の数を出します。各部品にマウスを重ねると使い方が出ます。右上の ``?`` でこのページを開きます。
ジョイントだけを選ぶと、対象のメッシュはそのままで、そのジョイントがアクティブなインフルエンスになります
(ビューポートでジョイントをクリックして、値を入れる・塗るインフルエンスを切り替えられます)。

画面
----

上から次のセクションが並び、見出しを押すと折りたためます。

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - セクション
     - 内容
   * - Influences
     - インフルエンスの一覧です。検索と「Used only」(選んだ頂点で使っているものだけ)で絞り込めます。
       Weight の列は選んだ頂点での平均の値で、見出しをクリックすると名前・ウェイトの順に並べ替えられます。クリックしたものがアクティブなインフルエンスになり、Weight の操作の対象になります。
       ダブルクリックで影響する頂点を選び、Lock のチェックでロックします(ロックしたものはどの操作でも値を変えません)。
       右クリックで、アクティブとの間のウェイトの移動・ランプ、全インフルエンス・選んだ頂点に影響するインフルエンスの選択、他を全部ロック・全部のロック/解除・ジョイントの選択・選んだジョイントの追加・外す(ウェイトは親へ移す)を選べます。
   * - Vertex Table
     - 選んだ頂点ごとの各インフルエンスの値の表です(既定は閉じています)。セルを書き換えるとその頂点の値が変わり、
       同じ列の複数のセルを選んでいれば全部に同じ値が入ります。合計が1でない行の Sum は赤、最大数を超えた行は黄色です。
   * - Select
     - Grow は選んだ頂点の隣まで選択を広げ、Shrink は縁の頂点を選択から外します。Loop・Ring は選んだエッジのループ・リングを選びます。
       Select by Weight は、アクティブなインフルエンスの値が最小〜最大の範囲にある頂点を選びます。
   * - Weight
     - Flood は、メッシュ全体(または選んだ頂点)のアクティブなインフルエンスを値の欄の値にします。0〜1 のボタンで、アクティブなインフルエンスの値を設定します(Shift で加算、Ctrl で減算)。
       Add/Scale と量の欄で ``-``・``+`` を押すと、量だけ足し引き、または (1 ± 量) 倍にします。値の欄と Set で任意の値を設定します。
       残りのロックしていないインフルエンスで、各頂点の合計を1にします。Paint は Maya の Paint Skin Weights ツールを、
       アクティブなインフルエンスで開きます(色でウェイトを見る・塗るときに使います)。
   * - Brushes
     - 独自のブラシです(Maya のユーザーペイントの仕組みを使い、プラグインは使いません)。Smooth は Smooth セクションの方法・半径・
       最大数の設定でなじませ、Sharpen は逆に境目をくっきりさせます。Remove はアクティブなインフルエンスを減らし、Add は増やします。
       Transfer は From のインフルエンスのウェイトをアクティブなインフルエンスへ移します。ブラシの大きさ・強さ・減衰は Maya の
       Tool Settings で変え、Q キーで抜けます。1ストロークを1回の Undo で戻せます。
   * - Blend
     - Slide をドラッグすると、アクティブなインフルエンスを右で増やし左で減らします。ソフト選択(B キー)が有効なら、
       減衰の割合に比例して変わります。離すと中央へ戻り、1回の Undo で戻せます。
       Soft Selection to Weight は、ソフト選択の減衰(選んだ頂点が1で、離れるほど小さい)をそのままアクティブなインフルエンスの値にします。
       Ramp to... は、アクティブなインフルエンスから選んだインフルエンスへ、2本のジョイントを結ぶ線に沿って選んだ頂点を配分します
       (Linear は均等、Smooth は両端がゆっくり)。一覧の右クリックからも選べます。
       Deformer to Weight は、メッシュの cluster・softMod・deltaMush などのデフォーマーのウェイトを、アクティブなインフルエンスの値にします
       (塗りやすいデフォーマーで範囲を作ってから、ジョイントのウェイトにできます)。
   * - Smooth
     - Hammer は選んだ頂点を隣の頂点の平均にし、飛び出した頂点をならします。Average は選んだ頂点をすべて同じ値(平均)にします。
       Smooth は強さ(0〜1)の分だけ隣の平均へ近づけ、回数だけ繰り返します。隣への重みの付け方(Method)は、Uniform(単純な平均)・
       Distance(辺の長さの逆数)・Cotangent(三角形の角度から求める、形に沿った重み)から選べます。Gap Radius を0より大きくすると、
       辺でつながっていない近くの頂点(指の間・別のパーツ)も平均に含め、Keep max は最大インフルエンス数を超えないようにします。
       Shell Average はつながったパーツ(シェル)ごとに全頂点を平均の値に、Shell Rigid は平均で最も大きい1つのインフルエンスへ100%にします
       (鎧の板・ボタンなど、曲げずに動かすパーツ用)。頂点を選んでいればその頂点を含むシェルだけに効きます。
   * - Copy / Mirror
     - Sample で見本の頂点を覚え、Average で選んだ頂点を見本の平均に、Proximity で見本との距離に応じた加重平均にします
       (エッジループの両端だけを整えて見本にし、間へ配ると滑らかな移り変わりになります)。Hold でメッシュ全体のウェイトを覚え、
       Fetch で1回の Undo で戻します。Copy で選んだ頂点のウェイト(複数なら平均)をコピーし、Paste で選んだ頂点へ貼り付けます。インフルエンスは名前で対応させるので、
       同じジョイントの別のメッシュへも貼れます。Mirror は軸と向き(+ to -)を選んで、メッシュ全体のウェイトを左右へ写します。
       Mirror Selected は、選んだ頂点だけを軸の反対側の頂点(許容量の距離以内で最も近い頂点)へ写し、
       インフルエンスは名前の左右(``L_``/``R_``・``_l``/``_r``・``Left``/``Right`` 等)で入れ替えます。
   * - Cleanup
     - Prune はしきい値未満の値を0に、Limit は1頂点のインフルエンスの数を上限までに、Round は小数の桁を丸め、
       Normalize は合計を1にします。頂点を選んでいればその頂点、メッシュを選んでいれば全体に効きます。
       Select Bad は、合計が1でない頂点と、skinCluster の最大数を超えた頂点を選びます。
   * - Game Cleanup
     - ゲームエンジンへ書き出す前のリダクションです。頂点ごとに、Prune Below 未満の値を0にし、大きい順に Max の数まで残し、
       合計1へ振り直してから、精度(2〜4桁、8-bit の 1/255、16-bit の 1/65535)へ丸めます。丸めの誤差は値の端数の大きい順に配るので、
       どの頂点も合計がちょうど1になります。Lock skin max は skinCluster の最大数を固定して、後で塗っても上限を超えないようにします。
       Remove unused は使われなくなったインフルエンスを外し、範囲(Scope)で、対象だけ・選んだメッシュ全部・シーンのバインド済みメッシュ全部を選べます(まとめて1回の Undo)。
       Analyze は最大使用数・頂点ごとの数の分布・上限超え・合計のずれ・極小の値・精度のずれ・不要なインフルエンスを表示し、
       Select Problems は Clean Up で直る頂点を選びます。Limit Bones は、skinCluster のインフルエンスを Max Bones 以下になるまで、
       ウェイトの合計の小さいジョイントから親へ移して外します(1メッシュあたりのボーン数に上限があるエンジン向け)。
       Analyze はウェイトの合計の小さいインフルエンス(先に外れる候補)と、左右の対が無いインフルエンス(ミラーの前の確認)も表示します。Remove Matching は、``*_end, *_helper`` のような
       名前のパターンに合うジョイントを、ウェイトを親へ移してから外します(書き出し前に変形に使わないジョイントを外すとき)。
       Copy Report は結果の文をクリップボードへコピーします。
   * - Bind
     - Closest Joint は、選んだ頂点を最も近いボーン(ジョイントから子のジョイントまでの線分)へ100%にします(硬い初期ウェイト。
       その後 Smooth でなじませます)。ジョイントとメッシュを選んで Bind を押すと、まだバインドしていないメッシュをバインドします(方法と最大数を選べます)。
       Bind Pose はバインドしたときのポーズへ戻します。Move Joints は、ジョイントを選んで押し、ジョイントを動かしてからもう一度押すと、
       メッシュの形を変えずにその位置をバインドの位置にします。Remove Unused はどの頂点にも影響していないインフルエンスを外します。
       Remove Selected Joints は、選んだジョイントを影響しているすべての skinCluster から外し、外す前にそのウェイトを最も近い親のインフルエンスへ移します
       (親子を一緒に選ぶと、残る祖先へ集まります。親にインフルエンスが無いジョイントは Maya の標準の再配分になります)。
   * - Skin Settings
     - skinCluster の設定(スキニング方法 Classic Linear・Dual Quaternion・Weight Blended、正規化の方法、最大数、最大数の維持)を読み込み、
       Apply で書きます(既定は閉じています)。
   * - Transfer / Files
     - Pick Source で元のメッシュを覚え、Add Source Influences で元にあって対象に無いインフルエンスを足し、Copy from Source で選んだ頂点(またはメッシュ全体)へ、最も近い頂点のウェイトを写します
       (メッシュの一部だけを直すときに使います)。Copy Skin to Meshes は、最初に選んだバインド済みのメッシュから、残りのメッシュへ最近点でウェイトをコピーします
       (バインドしていなければ同じジョイントでバインドします)。Export は頂点の位置を含む JSON へ書き出します。
       Import は、By vertex index(頂点数が同じこと)か By closest position(最も近い位置の頂点のウェイトを使うので、
       形やトポロジーが変わったメッシュにも使えます)で読み込みます。頂点を選んでいればその頂点だけに書きます。
       インフルエンスは名前で対応させ、Add missing はシーンにある同名のジョイントを足してから読み込みます。

各ボタンの操作は1回の Undo で戻せます。

ホットキー
----------

主な操作は runTimeCommand(Hotkey Editor の ``Custom Scripts`` > ``Skin Weight Kit``)として登録してあり、キーを割り当てられます。
``SkinWeightKitValueMenu`` を割り当てると、マウスの位置に値のメニュー(0〜1・Add/Subtract・Hammer・Smooth・Copy/Paste)が出て、
Paint Skin Weights ツールを開かずに、頂点を選んだまま値を入れられます(パネルでアクティブにしたインフルエンスが対象)。
