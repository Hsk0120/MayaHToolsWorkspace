copyCurrentScenePath
====================

今開いているシーンファイルのフルパスを、クリップボードへコピーするツールです。

開き方
------

HTools > rigging > copyCurrentScenePath。

画面
----

画面はありません。選ぶとすぐにコピーします。

使い方
------

1. 保存済みのシーンを開いた状態で、メニューから選びます。
2. シーンのフルパス(``C:/.../scene.ma`` のようなスラッシュ区切りの絶対パス)がクリップボードに入ります。
   Script Editor に ``Copied: <パス>`` と表示します。
3. エクスプローラーのアドレス欄やチャットなどへ貼り付けて使います。

注意・制限
----------

- 一度も保存していないシーンにはパスが無いため、\ ``The scene has not been saved, so it has no path.`` の警告を出して何もしません。
- コピーするのは Maya が返すパスそのままです(区切りは ``/``)。
- シーンは変更しないので、Undo の対象はありません。
