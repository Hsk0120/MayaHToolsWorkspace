リグアセットの表示ラベルと版を更新する
============================================================

HTools > system > rigPackageInspection

#. mlrigDefinitionを持つローカルのリグルートを1つ選択します。Inspect selected rig and scene dependenciesでシーンの参照元や公開チャンネルを表示します。

#. Read selected rig display informationを押し、Display labelとDisplay versionを編集します。Update selected rig display informationで選択したルートの表示情報を更新します。

#. 表示情報はルートのhtAssetLabelとhtAssetVersionに記録されます。再読込後も使用するにはシーンを保存します。
