Maya診断の起動条件を保存・比較する
============================================================

HTools > system > diagnosticLaunchPreview

#. Install root、Diagnostic Python file、Project、Log directoryを指定し、Compare launch settingsでMaya版ごとの引数を表示します。

#. History labelに識別名を入れてSave current preview to historyを押します。起動条件が個人のMaya設定フォルダーのHToolsDiagnosticHistoryに保存されます。

#. 履歴を2件選んでCompare two saved recordsを押すと、設定と版別引数の差が表示されます。1件選んでRestore selected history to previewを押すと入力欄に復元され、存在しないパスには(missing)が付きます。この画面の操作では診断スクリプトは実行されません。
