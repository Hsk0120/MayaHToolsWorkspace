二つの案件設定の差を調べる
============================================================

HTools > system > compareProjectSettings

#. Project AとProject BのBrowseから、それぞれのworkspace.melまたはプロジェクトJSONを選びます。workspace.melを比較する場合はプロジェクトフォルダーのパスも入力できます。

#. Compare settingsを押します。workspace.melでは文字列で指定されたファイル規則、JSONでは設定キーごとの値を照合します。両側で同じ形式を指定してください。

#. 結果のAとBで値を比較します。片側の設定にキーがなければ<missing>と表示されます。
