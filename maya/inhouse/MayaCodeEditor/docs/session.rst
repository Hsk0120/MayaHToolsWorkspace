自動保存と画面の復元
====================

Maya Code Editor は、ファイルへ保存していないコードも含めて、Maya を終了・再起動したあとに画面を復元します。

復元されるもの
--------------

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 対象
     - 内容
   * - タブ
     - 本文・順序・ファイルのパス・未保存状態・選択位置・アクティブなタブ・言語(Python / MEL)
   * - Explorer
     - フォルダーの一覧と表示状態
   * - 画面の状態
     - 開いていたか閉じていたか、フローティングか、ドックの配置(Maya のワークスペース)
   * - 設定
     - Preferences の各項目と文字サイズ(:doc:`preferences`)

**復元したコードは自動では実行しません。**

保存先と保全方式
----------------

``cmds.internalVar(userPrefDir=True)`` の下の ``MayaCodeEditor`` フォルダーです(Mayaのバージョンごとに別)。
0.8.0から、復元データを ``tabs.json.recovery`` へ追記します。

* ``snapshots/<UTC日時と識別子>.json``: タブ順・パス・言語・カーソル・未保存状態・Explorerと、本文の参照。
* ``bodies/<SHA256>.qz``: UTF-8本文をQtのqCompress形式で圧縮したもの。同じ本文は再利用します。
* 従来の ``tabs.json`` と ``tabs/<id>.txt`` は読込専用で移行し、上書き・削除しません。
  新形式の復元データは旧版では読めません。旧版へ戻す前に必要なタブを通常のファイルへ保存してください。
* ``ui.json`` と ``preferences.json`` の保存先・扱いは従来どおりです。

本文を先に保存し、全本文への参照を含む新しい世代を一時ファイルから確定します。
途中で終了しても直前の確定世代と本文は残ります。本文はSHA256で検証し、最新のデータが読めない場合は
読めるタブと親世代へ戻ります。破損ファイルも調査用に残します。

**復元履歴は自動削除しません。** 圧縮・重複排除を行いますが、編集に伴い容量と起動時の履歴確認時間は増えます。
必要な履歴を別の場所へバックアップし、全Mayaを閉じた状態で管理してください。
本文の復元先をネットワーク上へ置くと、同期書込の待ち時間が入力に影響します。通常のローカル保存先を推奨します。

自動保存のタイミング
--------------------

* 本文は確定した変更の通知で同期保存します。入力停止や終了通知を待たないので、連続入力中も保存されます。
  IMEの変換中でまだ文書に確定していない文字は対象外です。
* タブの並び・言語・Explorer等は最初の変更から1.5秒後までに保存します。連続操作で予約を先延ばしにしません。
* カーソル・選択だけの変更は30秒後、または本文保存・非表示・終了時にまとめます。
* 保存失敗時は消えない警告と出力欄の通知を表示し、1.5秒→3秒→6秒…最大60秒で再試行します。
  起動時に保存先を作れなかった場合は、保存先の状態を直してからMayaを再起動してください。
  警告が出たら **File > Save as…** で通常のファイルにも保存してください。確定できるまでは保存済み扱いにしません。
* 元の ``.py`` / ``.mel`` ファイルは上書きしません。外部で変更・削除された場合も復元した本文を未保存として保持します。
* 自動復元には保存時の整形を適用せず、復元したコードも自動実行しません。

複数のMayaを起動した場合
------------------------

全てのMayaが独立した世代を保存します。「最初に起動したMayaだけ保存」の制限はありません。
読込時点の確定世代を親として記録し、別のMayaの後続編集を上書きしません。
同じタブを別々に編集した場合は両方を別タブとして復元し、出力欄で知らせます。
終了順が逆でも、古い画面が後から保存しても、他のMayaの新しい本文を消しません。

同じ本文の同一タブは統合します。競合時は安全を優先して古い内容を含む複数のタブが出ることがあります。
復元したタブを確認し、必要なコードを通常のファイルへ保存してください。
``ui.json`` の配置・開閉状態は従来どおり最後に変更したMayaの状態です。
非表示で起動した場合もWindowメニューから開けば本文を復元できます。

タブを閉じたとき・過去の本文を取り戻すとき
------------------------------------------

タブの×やCtrl+WでDiscardを選んだタブは、次回の自動表示から外れますが、確定済みの本文と履歴は残します。
**File > Recover previous tabs…** で、UTC日時が付いた世代ファイルを選ぶと、その世代のタブを追加します。
現在のタブは置き換えず、元ファイルへの誤保存を防ぐため、新しい未保存タブとして開きます。
必要なら **Save as…** で保存先を指定してください。

エディター全体の非表示・プラグイン解除・通常終了でも保存します。保存できない場合は従来の保存確認を行います。
旧形式にしか残っていない本文は、保護した ``tabs/<id>.txt`` を通常のOpenから開くこともできます。

保護の限界
----------

ディスク故障、保存先の削除、書込不能中の強制終了、保存処理の途中での電源断、IMEの未確定文字まで
「必ず消えない」と保証するものではありません。確定前に停止した最新の編集は直前の確定世代まで戻る場合があります。
テキストのUndo履歴と出力ログは復元対象外です。重要なコードは通常のファイル保存と別媒体のバックアップを併用してください。
すでに旧版で保存されなかった、または削除された本文を新しい仕組みだけで取り戻すことはできません。

検証方法
--------

``tests/session_recovery.cpp`` は同時書込・旧形式・遅い書込元・履歴・本文破損・メタデータ破損・確定失敗と再試行・
2プロセスの強制終了を検証します。ビルド後の ``mayaCodeEditor_recovery_test.exe`` をMayaのQt DLLが見える環境で実行します。
``tests/run_recovery.py 2027`` (または2022)は専用Mayaを2つ起動し、12回の連続入力と最後の入力直後の強制終了、
2回の再起動、履歴の追加復元を検証します。ユーザーの設定・シーンは使用しません。
``tests/run_session.py`` は通常終了・解除・日本語・選択位置・未読込タブを検証します。

手動で確認する場合は、重要なコードを保存してから専用のテストタブを使ってください。

#. 同じMaya版を2つ起動し、それぞれのタブへ違う確認用文字列を書く。
#. 片方を通常終了し、もう片方を後から終了する。次回開いて両方の文字列があることを確かめる。
#. 同じ操作を終了順を逆にして行う。同じタブの内容を別々に変えた場合も両方が残ることを確認する。
#. IMEで日本語を確定し、ドッキング・非表示・再表示を行い、本文が保持されることを確認する。
#. テストタブをDiscardで閉じ、Recover previous tabs…から閉じる前の世代を追加復元する。

Maya 再起動時の画面の復元
-------------------------

* 前回 Maya Code Editor を開いていた場合は、Maya の保存済みワークスペースに登録された ``uiScript``\ (MEL の ``mayaCodeEditor -restore``)で
  画面を作り直します。プラグインのロード後、次のイベントループで C++ が前回の状態を確かめて復元するため、
  ``scripts/userSetup.py`` 経由の起動時自動ロード・Plug-in Manager での明示ロード・Maya のプラグイン autoload の
  いずれでも同じ復元が行われます。ドッキング・状態の保存と復元は C++(``mayaCodeEditor.mll``)が行い、
  ``userSetup.py`` は ``loadPlugin`` を呼ぶだけです。
* プラグインのロード前は ``uiScript`` の ``mayaCodeEditor`` コマンドが使えないため、Maya の起動直後は中身が空の
  ドックだけが残ることがあります。その場合 Maya Code Editor はドックを表示するだけにして、中身は Maya 自身が
  ``uiScript`` で作ります(Maya Code Editor 側で本体を差し込むと、Maya が作り直すときに破棄されるため)。
* 旧版で保存したワークスペースの ``uiScript``\ (Python の ``import maya_code_editor; maya_code_editor.restore()`` など)も、
  そのまま C++ の復元処理へ渡ります。
* ドックの入れ子・タブの位置は Maya 標準のワークスペースが保持します。Maya Code Editor は Maya のワークスペースを保存し直しません
  (保存は Maya と利用者の設定に任せます)。
* ``ui.json`` は、ドックの付け替え(ドッキング・フローティングの切り替え・ワークスペースの切り替え)や表示・非表示が
  起きたときと、閉じたとき・Maya の終了時に保存します(Maya へ毎秒問い合わせることはしません)。
* ``uiScript`` はプラグインがロード済みのときだけ ``mayaCodeEditor -restore`` を呼びます。未ロードなら空のドックを隠すだけで、
  プラグインをロードしません(以前は ``loadPlugin Maya Code Editor`` していたため、オートロードを切っていても Maya がロードしていました)。
  0.2.x で作られたドックには ``-requiredPlugin`` が残っていることがあり、その場合は Maya がロードします。
  一度プラグインをアンロードすると、ドックが作り直されて消えます。
* **ユーザーが閉じてから終了した場合は、自動では表示しません。**
* 元の Maya のワークスペースが削除された場合は、厳密な位置を復元できません。以前ドックしていた画面は下側に配置して警告します。
* 復元先は、Maya Code Editor 自身の ``workspaceControl`` を明示的に使います(内部の非表示のログウィンドウに入らないため)。
