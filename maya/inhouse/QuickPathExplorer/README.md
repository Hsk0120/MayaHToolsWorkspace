# QuickPathExplorer

Python＋Qtのファイルブラウザーです。PySide6を優先し、PySide2へフォールバックします。
Windows単体とMaya内で同じ画面を使用します。

## 画面と操作

- メニューはWindows／Mayaの用語に合わせ、削除はDelete、ファイルの情報はProperties、保存はSave Scene／Save Scene As、書き出しはExport Selectionと表示します。Deleteはごみ箱への移動で、完全削除ではありません。設定・履歴の内部識別子は変更しません。
- Mayaでは上部のSave Scene As…ボタンから、右ペインの保存フォームを開けます。名前・保存先・形式を確認してフォーム内のボタンを押すまで保存しません。新しく開いたQPEの保存形式はMaya Binary (.mb)です。Maya ASCII (.ma)も明示的に選べます。Save Sceneは既存シーンの形式を変更しません。
- QPEでMayaシーンを開く／保存する操作が成功すると、Maya標準のRecent Filesにも登録します。キャンセル・失敗・外部アプリで開いたファイル・Import／Referenceでは標準のシーン履歴を追加しません。

- 配色: Windows単体の新規設定はWindows Lightです。Windows標準Explorerの撮影を基準に、一覧と詳細欄は白、プレビューは薄いグレー、選択行はグレーで表示します。Windows Darkは暗い一覧・詳細欄と少し明るいプレビューで構成します。Aa→Colorで選択でき、既存の色設定は維持します。Windows themeではWindowsのアプリモード（ライト／ダーク）とアクセント色へ追従します。「Aa」→ColorでClassic Light / Windows theme / Windows Light / Windows Darkを選べ、OSの設定を変えずに白背景へ固定できます。Maya内はダーク配色を維持し、ホスト全体のパレットは変更しません。

- 左サイドバー: 初期状態は非表示。左上のアイコンで切り替え、Favorites・Recent items・Drivesを表示。両方でフォルダー・ファイルをアイコン付きで扱います。ファイルは単クリックで選択・プレビュー、ダブルクリックで開きます。ファイルの右クリックからAdd to Favoritesで登録できます。Recent itemsは移動先フォルダーと成功したOpen/Import/Referenceのファイルを最大10件保持します。
- 上段: フォルダー専用のカラムビュー。フォルダー名の左側にアイコンを表示します。読込完了した空の末尾カラムは非表示にし、起点の一覧・読込中・エラーの表示は保持します。
- 上段の各行は「フォルダーアイコン・名前・右端の階層矢印」の順です。空と確認できたフォルダーは矢印を省略します。
- 直近4列はフォルダー名から計算した幅を優先して保持し、遠い祖先から80pxまで縮小。DPI・UI倍率を適用し、収まらない場合は横スクロールになります。極端に長い名前や手動で狭めた列はホバーでフルパスを確認できます。
- 右クリックのSet as start folderで探索の起点を指定。上のStart folderボタンで解除できます。起点外へパス入力や履歴で移動した場合も解除し、ドライブ階層へ戻ります。起点はウィンドウ内だけの設定です。
- 下段左: 選択フォルダーのファイル一覧、名前検索、形式フィルター、ソート。
- ファイルはWindowsの関連付けアイコンで表示。ショートカットや実行ファイルは個別のアイコンを維持します。一覧・サムネイル・Favorites／Recent itemsでウィンドウ内のキャッシュを共有し、最大2,048件を最近使用した順に保持します。取得時はパス・更新日時・サイズを照合します。サイズはQt標準のロケール・単位・丸め方で表示し、並べ替えには元のバイト数を使用します。
- スクロールバーは7px基準の細い表示で、ホバー時に強調。カラムの縦バーはスクロールが必要な場合だけ表示します。
- カラム間の1pxの区切り線は常時表示。フォントはSegoe UIの通常ウェイトを共通に使用し、動的に追加する列にも同じ文字サイズを適用します。一覧の行高は22px基準で、文字サイズ・ホストDPI・UI倍率に追従します。入力欄・ツールバー・見出しの余白も同じ倍率で調整します。
- 右側の全高サイドバー: 初期非表示で右上のアイコンから切り替えます。Selected fileタブにOpen / Import / Reference、Save sceneタブに現在のシーンと保存先・保存操作を分離。プレビューは共通です。ファイルの選択で保存名を書き換えません。
- 選択フォルダーと下段の見出しを同系色で強調し、フォルダー名・ファイル件数・検索中の状態を表示。子フォルダーなし／ファイルなし／検索一致なしを区別します。
- カラムの右クリックから移動・新規フォルダー・お気に入り追加・パスコピー等を実行。Ctrl+Lでパス入力、Alt+左右で履歴移動、Alt+上で親へ移動。
- 最上段にサイドバー切替・戻る・進むのアイコンと、編集可能なフォルダーパス欄を表示。「★」からお気に入り・現在のプロジェクト・シーンの場所へ移動できます。
- 右上の「Aa」からStandard / Larger / Largestの表示プリセットを選択。Advanced settingsに文字サイズ（10〜24）・UI倍率（75〜200%）があり、実際の文字サイズも表示します。設定は即時反映・保存されます。
- フォルダー／ファイルの右クリックRename、F2、Returnで一覧内リネーム。ファイルは拡張子を除いた名前を最初に選択し、Enterまたはフォーカス移動で確定、Escapeで中止します。既存項目は上書きせず、不正なWindows名を拒否します。
- New Text Fileは空の.txtファイルを作成（拡張子省略時は自動追加）。Mayaシーンを作る場合はSave Scene Asから保存フォームを開き、保存先を確認して実行します。メニューを選んだだけでは保存しません。フォルダー改名時は子孫の履歴・お気に入り・探索起点も更新します。
- 右クリックでは元の選択・プレビューを保ち、メニュー対象を輪郭表示。Escで閉じても選択を変えません。空白用メニューにはOpen／Rename／Import／Referenceを出しません。
- 下段はCtrlで追加選択、Shiftで範囲選択。選択内の右クリックは選択集合、選択外ならその1件が対象です。複数Import／Referenceは対象一覧を確認してから順番に実行。途中のMayaエラーでは停止し、既に読み込んだ項目は残ります。Openは1件のみです。
- Space・Open・ダブルクリックは同じ規則でファイルを開きます。Maya内では.ma／.mbを現在のMayaで開き、それ以外はWindowsの関連付けアプリへ渡します。単体版はすべて関連付けアプリへ渡します。
- 縦スクロールはポインター下の一覧だけ、横スクロールはカラム全体へ適用。Shift＋ホイールも横移動です。列の端で別の列へ流さず、読み込み完了だけでは選択列へ引き戻しません。方向はOSから届く入力を使い、独自の慣性は追加しません。
- 斜めスクロールは縦横の両成分を処理します。幅変更時は左端に見えているカラムとその内部位置を基準に横位置を保持します。新しい階層への移動では子一覧を可視化します。
- 右クリックのInformation／空白のThis Folder Informationは、メニュー開始時の対象パスを表示します。メニュー外クリックは閉じるために消費し、次のクリックから通常操作へ戻ります。Open等の実行前には対象の存在と読取可否を再確認します。
- プレビューは要求番号・対象パス・表示先の有効性を確認して反映します。非表示にした画面の要求は失効し、再表示時に選択から読み直します。インライン改名ではIME変換中のEnter／Escapeを編集終了として扱いません。
- AaのColumn widthでFit window（直近4列以外を圧縮）／Fit folder namesを切替。列幅は最長のフォルダー名＋アイコン・矢印の余白を基準に80〜1040pxへ収め、DPIを適用します。短い名前だけの列に固定100pxの文字領域は確保しません。列右端の細い境界をドラッグすると名前幅モードへ切り替えて手動幅を保持し、ダブルクリックで内容幅へ戻します。モードは保存、手動幅はウィンドウ内だけ保持します。
- カラム下の列幅変更グリップは非表示。戻る・進むやパス入力で再訪すると横・各列の縦スクロール位置を復元（同一ウィンドウ内）。列幅は現在の表示領域から再計算します。カラム内のクリックでは、選択したフォルダーの子一覧を画面内に表示することを優先します。
- File/View/Goのメニューと見出し、下部のパス説明は省略。カラムを大きく表示。
- 分割幅とウィンドウサイズをホスト別に保存。お気に入り・最近の場所は両ホストで共有。

Maya版はフローティングの位置・サイズと開閉状態をMayaのバージョン別に保存します。ドッキング位置・タブの組み合わせはMaya標準のワークスペース保存／復元を利用します。×で閉じてもドックは保持され、Windowメニューで再表示すると元の配置に戻ります。Maya終了時に開いていたQPEは次回起動時に自動復元し、閉じていた場合は自動表示しません。Maya標準のワークスペース設定をリセット・削除した場合、そのドッキング配置は復元できません。画面外に保存された浮動位置は接続中の画面へ戻します。

`tools/qpe_dock_restore_test.py`は隔離したMaya設定を共有する4回の起動で、浮動位置・サイズ、閉じて再表示、ドックで再起動、閉じた状態の維持を検証します。ユーザーの作業中のMayaへ送信しないでください。

画像読込は別スレッドで処理し、選択が変わった場合は古い結果を表示しません。
Maya内ではMaya Code Editorと同じ`MQtUtil.dpiScale(1.0)`を起動時に読み、文字・アイコン・余白・カラム幅を拡大します。Maya全体のDPI設定は変更しません。Maya側の倍率変更後はMayaを再起動してください。
Windows単体ではQtのHigh DPI対応を使用します。UI倍率はホストのDPI倍率に重ねて適用し、文字サイズとUI倍率の設定はMaya／単体で別々に保存します。
コピー／移動／ごみ箱／Undo、再帰検索、タブ復元、動画／EXRの静止サムネイル、ラベル、一括改名、ZIP、比較／一方向同期を実装しています。使い方・対応範囲は[ファイル整理ガイド](ORGANIZER_GUIDE.md)を参照してください。`.mb`は保存時に生成した付随画像／情報でプレビューします。
テキストやシーンをプレビューするだけでは実行・ロードしません。

## Mayaで起動

このワークスペースの起動バッチでMayaを起動すると、`QuickPathExplorer.mod`と
`scripts/userSetup.py`により **Windows > QuickPathExplorer** が追加されます。
Mayaの日本語UIではWindowに対応するメニューから起動してください。
MayaCodeEditorと同じ標準Windowメニューへの登録方式で、重複登録を防ぎます。
通常のuserSetup実行が許可されている環境が前提です。

既に起動中のMayaでは、Script EditorのPythonタブから次を実行できます。

```python
import sys
path = r'C:/MayaHToolsWorkspace/maya/inhouse/QuickPathExplorer/python'
if path not in sys.path:
    sys.path.insert(0, path)
import qpeHost
qpeHost.installMenu()
qpeHost.show()
```

フローティング／ドックに対応します。閉じた後はメニューから再表示できます。
Maya終了時に開いていた場合は次回起動時に配置とタブを復元します。

**Saveは現在のシーン**を保存します。**Save As / Export Selectionは現在のフォルダーとFile nameで指定した保存先**を使用します。
完全な保存先は各ボタンのツールチップで確認できます。
未保存シーンのOpenには保存・破棄・キャンセル、既存ファイルへのSave As/Exportには上書き確認があります。
保存形式はMaya ASCII / Binaryです。Maya Optionsから標準の各オプション画面も開けます。

右サイドバーのSelected fileにはImport settings／Reference settingsがあります。各操作の設定は独立し、ボタンと右クリックメニューの両方へ適用します。設定はQPE専用設定へ保存し、名前付きプリセットも使用できます。Maya標準のPreferencesは変更しません。

- ネームスペース：ファイル名、任意指定（`shot:characterA`のような階層も可）、ルート。衝突時は既定で別ネームスペースを作り、Reuse existing namespaceで再利用します。ルートでは既存のルートを使い、同名ノードはMayaが改名します。
- 共通：グループ化、スクリプトノード実行、入れ子リファレンスの読込範囲。
- Import：リファレンス保持、重複シェーディングネットワーク削除、ベースアニメーションレイヤー統合、全ノード改名、フレームレート／再生範囲、バージョン無視。
- Reference：遅延読込、ロック。遅延読込中は読込範囲を適用しません。

FBXなど形式固有のトランスレーター設定や標準ダイアログの全項目の埋め込みには未対応です。それらはMaya Optionsから標準画面を使用してください。標準画面の設定はQPEの設定欄へ自動同期しません。
`tools/qpe_read_options_test.py`は専用Mayaで実ファイルを使い、ネームスペースと衝突・遅延読込を検証します（テストプロセス内のシーンを作り直すため、作業中のMayaへ送信しないでください）。
`.ma/.mb`以外のOpenはOSの関連付けアプリへ渡します。
単体版ではMaya専用の操作を無効化しています。

## Windows単体で起動

`launch_python.bat`を実行します。第1引数に開始フォルダーを指定できます。
このランチャーは単体exe、指定Python、PySide6導入済みPython、Maya2027〜2022のmayapyを順に探します。Maya GUIは起動しません。
Maya未導入PC向けには`tools/build_qpe_standalone.py`で配布フォルダーを生成できます。別途PySide6を導入済みのPythonなら
`python python/quickPathExplorer.py`でも起動できます。

設定はQtのGenericConfigLocation配下の`QuickPathExplorer/settings.json`に保存します。
検証時は`QPE_SETTINGS_FILE`で専用ファイルへ分離します。

## 検証

情報・プレビュー・操作欄は右側の全高サイドバーです。起動時は非表示で、最上段右端のアイコンで切り替えます。Mayaの「Save Scene As…」はサイドバーの保存タブを開きます。ファイル名の列は利用可能な幅に追従し、サイズ・タイプ・更新日時を右側に表示します。フォルダー／ファイル一覧は交互背景色です。

左右サイドバーの開閉では、反対側の幅を保持し、中央の一覧領域だけを伸縮します。左右どちらのサイドバーを表示した際も、末端の子フォルダーカラムまで横スクロールして可視化します。開閉時の幅変更と横位置調整は描画をまとめ、階層移動用アニメーションを使わずに反映します。その後の手動スクロールは維持し、通常の再描画では末尾へ戻しません。`tools/qpe_ui_sidebars.py`で左右各20回の開閉と末端カラムの可視範囲を検証できます。

未選択のファイルもダブルクリックで直接開きます。複数選択中でも開く対象はクリックした一件です。Mayaの未保存シーンの確認は維持します。Spaceのクイックルックは右サイドバーを閉じたまま使用できます。

`tools/qpe_ui_inspector.py`は未選択／別選択／複数選択からのダブルクリック、空白、サイドバー開閉、一覧幅、交互色、非表示中のクイックルックを検証します。専用Mayaでは実際のシーン読込と保存タブ表示も検証します。

`tools/qpe_ui_maya.py`は専用フォルダーでナビゲーション、検索、プレビュー、設定保存を検証します。
専用Maya GUIランナーから実行した場合はメニュー・保存・読込・キャンセルも検証します。
`tools/qpe_ui_navigation.py`は実クリック／キー入力で14種類の操作を検証し、子カラムの可視範囲・項目名・祖先の選択・下段のファイル一覧を照合します。
`tools/qpe_ui_context.py`は新規作成・改名・衝突／キャンセル・右クリック対象・表示設定・200%ホストDPIの模擬検証と、専用Maya内でImport／Referenceを検証します。4K実機や異なるDPIのモニター間移動は未検証です。
`tools/qpe_ui_ux.py`は探索起点・列位置・件数・インライン改名・作成種別・クイック移動・プリセット・保存先確認の一連の操作を検証します。`QPE_FFMPEG`を設定すると同じ操作を字幕付きで録画し、PNGと判定JSONも保存します。
`tools/qpe_ui_finder.py`は選択を保つ右クリック、対象輪郭、複数選択、空白メニュー、ピクセル／ホイールの軸分離、手動横位置、列境界操作、Return／Spaceを検証・録画します。Finderの慣性やMac実機のクリック透過を完全再現したものではありません。
`tools/qpe_ui_p0.py`は対象固定・対象消失、プレビュー要求の逆順完了／同じパスへの再訪／100回の連続選択／非表示・破棄、両軸スクロール、カラム基準の位置保持、合成IMEイベントを検証します。`result.json`の`status`は自動テスト実行結果、`acceptance`は受け入れ全体の状態です。部分検証の`automatedStatus`を受け入れケース全体の合格と扱わないでください。ディレクトリ列挙は`qpeDirectoryModel.py`で非同期実行し、パス・要求世代・表示先の有効性を確認してから行へ反映します。`tools/qpe_ui_directory.py`で一覧データの逆順完了、A→B→A、旧エラー、100回切替、非表示・破棄を注入検証します。古い要求には協調キャンセルも通知しますが、採否はキャンセル成功に依存しません。物理入力・実IME・別アプリからの初回クリックも未検証です。`QPE_TEST_DOCK=1`で専用Mayaをドック表示にして検証できます。
`tools/qpe_ui_record.py`は専用Maya内の実ウィジェットを自動操作中に連続キャプチャし、操作字幕・クリック位置を含むMP4とPNGを保存します。`QPE_FFMPEG`でH.264対応FFmpegのパスを指定します。OSの画面全体や作業中のユーザーシーンは録画しません。
レビュー用動画・画像は`.maya-output/verification/`へ保存し、依頼時にDriveへアップロードします。レビュー報告には毎回、実際のDrive閲覧リンクを添付します。未撮影・未アップロードの場合はその状態を明記します。
ユーザーが作業中のMayaへテストを送らないでください。
Maya 2022/2027の専用GUIおよび単体Qt5/Qt6で主要操作を確認しています。
Maya 2023〜2026、ネットワーク共有、大規模フォルダーでの現行UIの速度は未検証です。

## 比較用プロトタイプ

C++版は`src/`、元のPython版は`python/qpePrototype.py`、ホスト接続は`python/qpePrototypeHost.py`に保持しています。
新しい2段UIと比較用の旧UIは異なるため、旧計測結果は現行UIの性能保証には使用しません。
比較用ランチャーは`launch_cpp.bat`、計測は`tools/qpe_compare.py --rounds 6`です。
C++版のビルドは`python tools/build_maya_plugin.py maya/inhouse/QuickPathExplorer --versions 2027`です。
Maya内の旧比較用UIは`qpePrototypeHost.show('cpp')` / `qpePrototypeHost.show('python')`で開けます。

ファイルアイコンはWindows Shellの関連付けを使用します。関連付け自体は変更しません。下段のThumbnailsではQPEの画像・動画・シーン付随PNGを表示できます。Windowsの全形式のサムネイルやクラウド同期バッジの完全再現は対象外です。非Windows環境・取得失敗時はQtのアイコンへフォールバックします。

初期の上下配分は約40:60でファイル一覧を優先します。旧レイアウト設定からの初回移行時は上下配分だけ更新し、以後の手動調整は保存します。ファイル欄の最低高さを確保し、右側の最低幅を縮めています。極端に狭い幅や大きな倍率では横スクロールが必要です。
保存名は全幅の独立した入力欄です。保存タブではプレビューを畳み、操作を上寄せします。詳細欄はファイル名・プレビュー・基本情報・操作の順に表示します。Import / Reference settingsで読込設定を展開でき、折り畳んでも指定値は保持します。右ペインは高さが足りなければ縦スクロールできます。最上段のSet start folderで現在地を探索起点にでき、Start folderの×で全階層へ戻せます。

上部の「+」でフォルダータブを追加し、タブの×で閉じられます（最後の一枚は残ります）。各タブは移動履歴・検索条件・選択・カラム表示位置を独立して保持し、タブ一覧も次回へ復元します。下部フッターは表示中のファイル件数・選択件数・選択サイズを表示します。Include subfoldersを選ぶと子階層のファイルも下段一覧と件数に含みます。

タブと詳細表示の回帰検証は `tools/qpe_ui_tabs.py <出力先>` で実行します。

フォルダータブは標準240px・最小100px（DPI/UI倍率適用前）で、空き幅に応じて均等に縮みます。下限を超える枚数では左右の送りボタンが表示されます。「+」は最後のタブの隣に置かれ、閉じる・ウィンドウの拡縮で幅が再配分されます。

タブはWindows Explorerを参考にした角丸・左寄せの名前・OS標準フォルダーアイコンを使用します。閉じるボタンは細い×とホバー時の背景のみで表示し、クリック領域は28px（DPI/UI倍率適用前）です。上段カラムはフォルダー名の左にOS標準フォルダーアイコンを表示し、右端は子階層の矢印だけにしています。自動幅はアイコンの分も含めて計算します。


追加の操作機能は[ファイル整理ガイド](ORGANIZER_GUIDE.md)の「操作統一・検索・作業セット・転送回復」を参照してください。関連付けアプリで開く操作、パス補完、タブ固定／場所ロック、本文検索、ZIP内部閲覧、転送ジョブ復元、ファイル使用状況の診断、Windows取得状態表示を利用できます。転送再開は項目単位で、途中ファイルは先頭から転送します。

回帰テスト・章別動画の再実行と、物理入力や外部サービスが必要な確認手順は[操作検証ガイド](VERIFICATION.md)を参照してください。

表示設定はファイル一覧の右上の **View** にまとめています。Details / Thumbnails / Extended details、Include subfolders、グループ化、タグ、列設定を選べます。適用中の条件は一覧上のラベルに表示され、×で個別解除できます。ViewはEscapeまたは外側クリックで閉じます。

ライト／ダーク／Mayaで部品の余白・枠・操作状態を共通化しています。新規設定の標準文字は13px（DPI/UI倍率適用前）で、既存の文字設定は維持します。Aa → Row spacingのCompact（24px）／Comfortable（28px）は文字倍率とは独立した行間設定です。文字が大きい場合は行高も広がります。細いスクロールバーの見た目に対し操作領域は12px確保し、カラム境界は常に表示します。

### 操作用語

タブ一式は **Tab set**、QPEの操作履歴は **File operation history** と表記します。MayaのWorkspaceやWindowsのFile Historyとは別の機能です。ファイル一覧の **Extension** は拡張子、**Extended details** はタグ等を含む詳細一覧です。**Compare folders and copy changes** は宛先へ一方向に変更をコピーし、宛先だけのファイルは残します。競合時の **Keep both (new name)** は別名で両方保持します。左側の **Recent items** はQPEのファイル・フォルダー履歴、アドレス欄の **Recent folders** は移動先フォルダーの履歴です。

Maya用の上部バーには **New Scene** と **Save Scene As…** を表示します。New Sceneは未保存の変更があればSave／Discard／Cancelを確認します。保存をキャンセルした場合や保存に失敗した場合は、現在のシーンを維持します。Windows単体ではNew Sceneを表示しません。

左サイドバーの **Drives** はOSから取得したドライブ一覧です。ドライブをクリックするとそのルートへ移動します。Maya標準のOpen/Recent FilesやQPEでシーンを開いた場合は、現在のタブをシーンのフォルダーへ移動します（場所をロックしたタブは既存の規則どおり新しいタブで移動）。保存・新規シーン・読込キャンセルでは閲覧中の場所を変更しません。

### 小さいMayaドックでの表示

QPEの内容の最小サイズがMayaのドック全体を押し広げないようにしています。ドックを小さくした場合は必要な方向にスクロールして操作できます。タイムスライダーより下の固定行だけに隣接したドックは、QPEを表示・復元する際に、サイズ変更できるタイムスライダーの上へ移動します。右・左ドックや、下側にサイズ変更できる別のドックがある配置、他エディターとの共有タブは維持します。手動で固定行の下へ移動して縮小できなくなった場合は、WindowメニューからQPEをもう一度表示してください。

ドックの監視対象はQPE本体と専用workspaceControlだけです。Maya本体・共有タブ・共有splitterのサイズ制約は変更しません。削除直後の再生成では旧監視と予約を解除し、新しい画面へ結び直します。回帰検証は `python tools/qpe_audit_runner.py <出力先> --maya 2027 --suites dock_lifetime dock_resize`（2022も指定可能）で実行できます。
