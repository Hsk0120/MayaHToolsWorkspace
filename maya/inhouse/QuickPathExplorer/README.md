# QuickPathExplorer

Python＋Qtのファイルブラウザーです。PySide6を優先し、PySide2へフォールバックします。
Windows単体とMaya内で同じ画面を使用します。

## Maya用の単一mll版

`release/plug-ins/windows/<Maya年>/quickPathExplorer.mll` に、そのMaya用の
Pythonモジュールとアイコンを内蔵します。配布するQPEファイルはこの1個で、
外部の.pyやQPE専用DLLを参照・展開しません。Maya付属のPython/PySide/Qtは使用します。
UI・シーン操作は既存実装を内蔵し、一覧の検索・ソート・表示値・行寸法・可視項目の
Shellアイコン取得と画像読込をC++で行う構成です。UI全体のC++書換えではありません。

初回は仮アイコンで一覧を表示し、見えている項目のWindowsアイコンを別スレッドで取得します。
画像サムネイルは維持します。同じ列挙結果の再適用を省きますが、再列挙・監視・要求世代の
照合は省かないため、再訪時の変更検出を維持します。Qt全体のスタイルや入力処理は変更しません。

ビルド（開発用PythonとMaya devkit/MSVCが必要）:

```powershell
python tools/build_maya_plugin.py maya/inhouse/QuickPathExplorer --versions 2022 2027 --build-root .maya-output/qpe-plugin-build
```

起動方法:

1. Mayaを再起動します。`QuickPathExplorer.mod` は対応年の固定リリース先だけを登録し、
   Python版のuserSetupは実行しません。旧Python版が読み込まれたセッションへ重ねてロードしないでください。
2. Plug-in Managerから、Mayaの年に対応するmllをロードします。MayaのSecurity許可は利用者が判断します。
3. Window → QuickPathExplorer、またはMELの `quickPathExplorer;` で開きます。
4. アンロードはQPEのUIとコールバックだけを解除します。処理中のファイル操作・生存する
   ネイティブ部品・Shellワーカーがある間は解除を拒否します。処理終了後に再実行してください。

Maya 2022/2027の専用環境で画像読込・表示切替・シーン操作・FBX・ドック寿命を検証しています。
表示更新時には一覧レイアウトを確定し、Windowsアクセシビリティが途中の状態へ再入しないようにします。
画像の読込と寸法取得はGILを解放するC++入口で行い、Qtのファイルオブジェクトを同じワーカー内で破棄します。
Maya 2023〜2026はビルドのみで、実機操作は未確認です。実IME、ネットワーク共有、長時間運用は別途確認が必要です。
試験用DLL `qpe_native_bridge_test.dll` はMayaを使わない部品検証専用で、配布不要です。

専用prefsで、MCEと同様に固定リリース先のmllを検証する入口（毎回コピーしません）:

```powershell
python tools/qpe_native_runner.py .maya-output/qpe-native-check --version 2027
python tools/qpe_native_runner.py .maya-output/qpe-native-speed --version 2027 --suites qpe_native_benchmark
```

このテストは専用Mayaを起動します。Securityダイアログが出た場合は手動確認が必要です。
許可なしのタイムアウトや実行できなかったケースを合格扱いにしません。

## 画面と操作

- メニューはWindows／Mayaの用語に合わせ、削除はDelete、ファイルの情報はProperties、保存はSave Scene／Save Scene As、書き出しはExport Selectionと表示します。Deleteはごみ箱への移動で、完全削除ではありません。設定・履歴の内部識別子は変更しません。
- Mayaでは上部のSave As…ボタンから、右ペインの保存フォームを開けます。名前・保存先・形式を確認してフォーム内のボタンを押すまで保存しません。新しく開いたQPEの保存形式はMaya Binary (.mb)です。Maya ASCII (.ma)も明示的に選べます。Save Sceneは既存シーンの形式を変更しません。
- QPEでMayaシーンを開く／保存する操作が成功すると、Maya標準のRecent Filesにも登録します。キャンセル・失敗・外部アプリで開いたファイル・Import／Referenceでは標準のシーン履歴を追加しません。

- Windows単体のウィンドウ: 独立したタイトル段を省き、タブ段の右端に最小化・最大化／復元・閉じるを配置します。空白部分をドラッグすると移動、ダブルクリックで最大化／復元、端をドラッグするとリサイズできます。Maya内のドック／フロート枠は変更しません。
- 配色: Windows単体の新規設定はWindows themeです。Windowsのアプリモード（ライト／ダーク）とアクセント色へ自動追従します。Windows標準Explorerの撮影を基準に、一覧と詳細欄は白、プレビューは薄いグレー、選択行はグレーで表示します。Windows Darkは暗い一覧・詳細欄と少し明るいプレビューで構成します。Display settings → Colorで選択でき、既存の色設定は維持します。Windows themeではWindowsのアプリモード（ライト／ダーク）とアクセント色へ追従します。Tools → Navigation / scene → Display settings→ColorでClassic Light / Windows theme / Windows Light / Windows Darkを選べ、OSの設定を変えずに白背景へ固定できます。Maya内はダーク配色を維持し、ホスト全体のパレットは変更しません。

- 左サイドバー: 初期状態は非表示。左上のアイコンで切り替え、Favorites・Recent items・Drivesを表示。両方でフォルダー・ファイルをアイコン付きで扱います。ファイルは単クリックで選択・プレビュー、ダブルクリックで開きます。ファイルの右クリックからAdd to Favoritesで登録できます。Recent itemsは移動先フォルダーと成功したOpen/Import/Referenceのファイルを最大10件保持します。
- 上段: フォルダー専用のカラムビュー。フォルダー名の左側にアイコンを表示します。読込完了した空の末尾カラムは非表示にし、起点の一覧・読込中・エラーの表示は保持します。
- 上段の各行は「フォルダーアイコン・名前・右端の階層矢印」の順です。空と確認できたフォルダーは矢印を省略します。
- 直近4列はフォルダー名から計算した幅を優先して保持し、遠い祖先から80pxまで縮小。DPI・UI倍率を適用し、収まらない場合は横スクロールになります。極端に長い名前や手動で狭めた列はホバーでフルパスを確認できます。
- 右クリックのSet as start folderで探索の起点を指定。上のStart folderボタンで解除できます。起点外へパス入力や履歴で移動した場合も解除し、ドライブ階層へ戻ります。起点はウィンドウ内だけの設定です。
- 下段左: 選択フォルダーのファイル一覧、名前検索、形式フィルター、ソート。
- ファイルはWindowsの関連付けアイコンで表示。ショートカットや実行ファイルは個別のアイコンを維持します。一覧・サムネイル・Favorites／Recent itemsでウィンドウ内のキャッシュを共有し、最大2,048件を最近使用した順に保持します。取得時はパス・更新日時・サイズを照合します。サイズはQt標準のロケール・単位・丸め方で表示し、並べ替えには元のバイト数を使用します。
- スクロールバーは7px基準の細い表示で、ホバー時に強調。カラムの縦バーはスクロールが必要な場合だけ表示します。
- カラム間の1pxの区切り線は常時表示。フォントはWindows／Mayaのホスト標準フォントの通常ウェイトを使用し、動的に追加する列にも同じ文字サイズを適用します。英字用フォントの固定指定を避け、日本語の初回描画時に発生する代替フォント探索を減らします。一覧の行高はCompactで24px基準で、文字サイズ・ホストDPI・UI倍率に追従します。入力欄・ツールバー・見出しの余白も同じ倍率で調整します。
- 右側の全高サイドバー: 初期非表示で右上のアイコンから切り替えます。Maya内ではOpen / Import / Reference / Saveの操作別タブに分離し、設定の下に該当操作の実行ボタンを配置。ファイル詳細とプレビューはFile detailsを開いた時だけ表示します。ファイルの選択で保存名を書き換えません。
- 選択フォルダーと下段の見出しを同系色で強調し、フォルダー名・ファイル件数・検索中の状態を表示。子フォルダーなし／ファイルなし／検索一致なしを区別します。
- カラムの右クリックから移動・新規フォルダー・お気に入り追加・パスコピー等を実行。Ctrl+Lでパス入力、Alt+左右で履歴移動、Alt+上で親へ移動。
- 最上段にサイドバー切替・戻る・進むのアイコンと、編集可能なフォルダーパス欄を表示。「★」からお気に入り・現在のプロジェクト・シーンの場所へ移動できます。
- 右上のTools → Navigation / scene → Display settingsからVery Small / Smaller / Standard / Larger / Largestの表示プリセットを選択。Very Smallは10px・Smallerは11px（ホストDPI適用前、UI倍率100%）です。常時表示のFont sizeで文字サイズ（10〜24）を直接変更できます。Advanced settingsにはUI倍率（75〜200%）があり、実際の文字サイズも表示します。QPEのファイル・フォルダー一覧、サイドバー、タブにフォーカスがあるときはCtrl＋＋／Ctrl＋－で文字サイズを1段ずつ変更し、Ctrl＋0で文字サイズを12へ戻します（Ctrl＋＝、テンキーの＋／－も可）。UI倍率は保持し、検索・パス・リネーム等の入力中や他のMayaビューでは処理しません。設定は即時反映・保存されます。
- フォルダー／ファイルの右クリックRename、F2、Returnで一覧内リネーム。ファイルは拡張子を除いた名前を最初に選択し、Enterまたはフォーカス移動で確定、Escapeで中止します。既存項目は上書きせず、不正なWindows名を拒否します。
- New Text Fileは空の.txtファイルを作成（拡張子省略時は自動追加）。Mayaシーンを作る場合はSave Scene Asから保存フォームを開き、保存先を確認して実行します。メニューを選んだだけでは保存しません。フォルダー改名時は子孫の履歴・お気に入り・探索起点も更新します。
- 右クリックでは元の選択・プレビューを保ち、メニュー対象を輪郭表示。Escで閉じても選択を変えません。空白用メニューにはOpen／Rename／Import／Referenceを出しません。
- 下段はCtrlで追加選択、Shiftで範囲選択。選択内の右クリックは選択集合、選択外ならその1件が対象です。複数Import／Referenceは対象一覧を確認してから順番に実行。途中のMayaエラーでは停止し、既に読み込んだ項目は残ります。Openは1件のみです。
- Space・Open・ダブルクリックは同じ規則でファイルを開きます。Maya内では.ma／.mb／.fbxを現在のMayaで扱い、それ以外はWindowsの関連付けアプリへ渡します。FBXの動作はOpenタブのFBX / File Contentで切り替えられます。単体版はすべて関連付けアプリへ渡します。
- 縦スクロールはポインター下の一覧だけ、横スクロールはカラム全体へ適用。Shift＋ホイールも横移動です。列の端で別の列へ流さず、読み込み完了だけでは選択列へ引き戻しません。方向はOSから届く入力を使い、独自の慣性は追加しません。
- 斜めスクロールは縦横の両成分を処理します。幅変更時は左端に見えているカラムとその内部位置を基準に横位置を保持します。新しい階層への移動では子一覧を可視化します。
- 右クリックのInformation／空白のThis Folder Informationは、メニュー開始時の対象パスを表示します。メニュー外クリックは閉じるために消費し、次のクリックから通常操作へ戻ります。Open等の実行前には対象の存在と読取可否を再確認します。
- プレビューは要求番号・対象パス・表示先の有効性を確認して反映します。非表示にした画面の要求は失効し、再表示時に選択から読み直します。インライン改名ではIME変換中のEnter／Escapeを編集終了として扱いません。
- Display settingsのColumn widthでFit window（直近4列以外を圧縮）／Fit folder namesを切替。列幅は最長のフォルダー名＋アイコン・矢印の余白を基準に80〜1040pxへ収め、DPIを適用します。短い名前だけの列に固定100pxの文字領域は確保しません。列右端の細い境界をドラッグすると名前幅モードへ切り替えて手動幅を保持し、ダブルクリックで内容幅へ戻します。モードは保存、手動幅はウィンドウ内だけ保持します。
- カラム下の列幅変更グリップは非表示。戻る・進むやパス入力で再訪すると横・各列の縦スクロール位置を復元（同一ウィンドウ内）。列幅は現在の表示領域から再計算します。カラム内のクリックでは、選択したフォルダーの子一覧を画面内に表示することを優先します。
- File/View/Goのメニューと見出し、下部のパス説明は省略。カラムを大きく表示。
- 分割幅とウィンドウサイズをホスト別に保存。お気に入り・最近の場所は両ホストで共有。

Maya版はフローティングの位置・サイズと開閉状態をMayaのバージョン別に保存します。ドッキング位置・タブの組み合わせはMaya標準のワークスペース保存／復元を利用します。×で閉じてもドックは保持され、Windowメニューで再表示すると元の配置に戻ります。Maya終了時に開いていたQPEは次回起動時に自動復元し、閉じていた場合は自動表示しません。Maya標準のワークスペース設定をリセット・削除した場合、そのドッキング配置は復元できません。画面外に保存された浮動位置は接続中の画面へ戻します。

`tools/qpe_dock_restore_test.py`は隔離したMaya設定を共有する4回の起動で、浮動位置・サイズ、閉じて再表示、ドックで再起動、閉じた状態の維持を検証します。ユーザーの作業中のMayaへ送信しないでください。

画像読込は別スレッドで処理し、選択が変わった場合は古い結果を表示しません。
Maya内ではMaya Code Editorと同じ`MQtUtil.dpiScale(1.0)`を起動時に読み、文字・アイコン・余白・カラム幅を拡大します。Maya全体のDPI設定は変更しません。Maya側の倍率変更後はMayaを再起動してください。
Windows単体ではQtのHigh DPI対応を使用します。UI倍率はホストのDPI倍率に重ねて適用し、文字サイズとUI倍率の設定はMaya／単体で別々に保存します。
コピー／移動／ごみ箱／Undo、再帰検索、タブ復元、動画／EXRの静止サムネイル、ラベル、一括改名、ZIP、比較／一方向同期を実装しています。使い方・対応範囲は[ファイル整理ガイド](ORGANIZER_GUIDE.md)を参照してください。`.mb`は保存時に生成した付随画像／情報でプレビューします。
テキストやシーンをプレビューするだけでは実行・ロードしません。

## Mayaで起動

このワークスペースの起動バッチでMayaを起動すると、`QuickPathExplorer.mod`と
`scripts/userSetup.py`により **Windows > QuickPathExplorer** が追加されます。
Mayaの日本語UIではWindowに対応するメニューから起動してください。
MayaCodeEditorと同じ標準Windowメニューへの登録方式で、重複登録を防ぎます。
通常のuserSetup実行が許可されている環境が前提です。

既に起動中のMayaでは、Script EditorのPythonタブから次を実行できます。

```python
import sys
path = r'C:/MayaHToolsWorkspace/maya/inhouse/QuickPathExplorer/python'
if path not in sys.path:
    sys.path.insert(0, path)
import qpeHost
qpeHost.installMenu()
qpeHost.show()
```

フローティング／ドックに対応します。閉じた後はメニューから再表示できます。
Maya終了時に開いていた場合は次回起動時に配置とタブを復元します。

**Saveは現在のシーン**を保存します。**Save As / Export Selectionは現在のフォルダーとFile nameで指定した保存先**を使用します。
完全な保存先は各ボタンのツールチップで確認できます。
未保存シーンのOpenには保存・破棄・キャンセル、既存ファイルへのSave As/Exportには上書き確認があります。
保存形式はMaya ASCII / Binaryです。Maya Optionsから標準の各オプション画面も開けます。

右サイドバーのImport／Referenceタブには、それぞれの読込設定と実行ボタンがあります。ネームスペースは常時編集でき、Specify namespaceを選ぶと入力欄を表示します。追加設定はAdvanced optionsで展開します。各操作の設定は独立し、ボタンと右クリックメニューの両方へ適用します。設定はQPE専用設定へ保存し、名前付きプリセットも使用できます。Maya標準のPreferencesは変更しません。

- ネームスペース：ファイル名、任意指定（`shot:characterA`のような階層も可）、ルート。衝突時は既定で別ネームスペースを作り、Reuse existing namespaceで再利用します。ルートでは既存のルートを使い、同名ノードはMayaが改名します。
- 共通：グループ化、スクリプトノード実行、入れ子リファレンスの読込範囲。
- Import：リファレンス保持、重複シェーディングネットワーク削除、ベースアニメーションレイヤー統合、全ノード改名、フレームレート／再生範囲、バージョン無視。
- Reference：遅延読込、ロック。遅延読込中は読込範囲を適用しません。

FBXを選択すると右サイドバーのOpenタブに **FBX / File Content** が表示されます。Open・ダブルクリック・Spaceに使うモードを切り替え、QPE専用設定へ即時保存します。サイドバー非表示中も上部の **FBX: …** メニューから切り替えられ、**FBX settings…** で設定欄を表示できます。

| モード | 動作 |
| --- | --- |
| Open as scene（既定） | 未保存確認後、現在のシーンをFBXへ切り替える |
| Add | 現在のシーンに追加する |
| Add and update animation | 不足するノードを追加し、一致する対象のアニメーションを更新する |
| Update animation only | 現在のシーンに一致する対象だけを更新し、存在しない対象は追加しない |
| Update animation (keyed transforms) | Maya標準のkeyed-transformモードで、未キーのトランスフォームを保持しながら更新する |

**Update playback range from FBX** は再生範囲の更新です（既定OFF）。読込には標準のfbxmayaを使用し、アニメーション読込を有効にします。FBXの名前・階層に基づくMaya標準の照合であり、別名リグへのリターゲットではありません。更新モードは現在のシーン名と内容を保持し、更新対象のアニメーションを書き換えるため、必要に応じて事前にシーンを保存してください。

上記はFBXのOpen用設定です。Import／Referenceボタンは既存の別設定を使います。標準FBXダイアログの全項目の埋め込みではなく、上記以外のトランスレーター設定は現在のMaya設定に従います。QPEの読込中だけ設定を適用し、成功・失敗のどちらでも標準FBX設定を復元します。Maya Optionsから標準画面も使用できますが、その設定はQPEの欄へ自動同期しません。
`tools/qpe_read_options_test.py`は専用Mayaで実ファイルを使い、ネームスペースと衝突・遅延読込を検証します（テストプロセス内のシーンを作り直すため、作業中のMayaへ送信しないでください）。
`.ma/.mb/.fbx`以外のOpenはOSの関連付けアプリへ渡します。
単体版ではMaya専用の操作を無効化しています。

`tools/qpe_fbx_test.py`は専用Maya GUIランナーから実行します。実FBXのキー更新・ノード追加有無・シーン切替・未保存キャンセル・FBX設定の復元と、読込失敗の注入を検証し、実ウィジェットを録画します。作業中のMayaへ送信しないでください。

## Windows単体で起動

このフォルダーへビルド済みの`QuickPathExplorer.exe`と`_internal`を配置した場合は、exeを直接起動できます。
リポジトリ直下で`python tools/build_qpe_standalone.py --install-project`を実行すると、
隔離フォルダーでビルドしてからこのフォルダー直下へ配置します。`_internal`はexeと同じ場所に必要です。
生成したexeと`_internal`はGitへ登録しません。

`launch_python.bat`を実行します。第1引数に開始フォルダーを指定できます。
このランチャーは単体exe、指定Python、PySide6導入済みPython、Maya2027〜2022のmayapyを順に探します。Maya GUIは起動しません。

### ファイル・フォルダーの削除と復元

DeleteはWindowsのごみ箱へ直接移動します。削除前に内容全体を読み込んだり、Cドライブへ復元用コピーを作ったりしません。ごみ箱へ移動できない場合は完全削除へ切り替えず中止します。

File UndoまたはWindowsのごみ箱から復元できます。**ごみ箱を空にする、Windowsが項目を消すなどで原本がなくなると、QPEからも復元できません。** QPEの履歴整理はWindowsのごみ箱を空にしません。旧版が作った独立バックアップの履歴も復元できます。

復元先に同名項目がある場合は上書きしません。削除のRedoでは、復元後のファイルID・サイズ・更新時刻とフォルダー構成の変更を検出します。内容の再ハッシュは行わないため、同じファイルID・サイズ・時刻を保って内容だけを書き換えた場合の検出は保証しません。

Mayaではナビゲーション・一覧・操作ペインの背景と文字の強弱を統一し、交互行の背景と区切りを控えめにしています。右ペインは対象ファイル、操作タブ、設定、実行ボタンの順に表示し、有効な主操作をアクセント色で強調します。FBXの説明は幅に応じて折り返し、読込方式を変更しても全文を表示します。Windowsのファイル関連付けアイコンは維持し、上部の操作アイコンは線画で揃えています。

### 操作用語

タブ一式は **Tab set**、QPEの操作履歴は **File operation history** と表記します。MayaのWorkspaceやWindowsのFile Historyとは別の機能です。ファイル一覧の **Extension** は拡張子、**Extended details** はタグ等を含む詳細一覧です。**Compare folders and copy changes** は宛先へ一方向に変更をコピーし、宛先だけのファイルは残します。競合時の **Keep both (new name)** は別名で両方保持します。左側の **Recent items** はQPEのファイル・フォルダー履歴、アドレス欄の **Recent folders** は移動先フォルダーの履歴です。

Maya用の上部バーには **New Scene** と **Save As…** を表示します。Save Asは従来のSave Scene Asと同じ保存フォームを開きます。New Sceneは未保存の変更があればSave／Discard／Cancelを確認します。保存をキャンセルした場合や保存に失敗した場合は、現在のシーンを維持します。Windows単体ではNew Sceneを表示しません。

左サイドバーの **Drives** はOSから取得したドライブ一覧です。Windowsエクスプローラの表示名（ボリューム名とドライブレター）を使い、名前・使用量バー・空き容量/総容量を分けて表示します。狭い幅でも容量を読めるよう空きと総容量は別行にし、長い名前はレターを残して中間省略します。全文はツールチップで確認できます。空き10%未満ではバーが赤、それ以外は青になります。容量はバックグラウンドで取得し、表示中は約30秒ごとに更新します。取得できない媒体は `Capacity unavailable` と表示します。現在表示しているフォルダーの所属ドライブをハイライトし、戻る/進む・タブ切替にも追従します。ファイル一覧へフォーカスを移してもハイライトは維持します。ドライブをクリックするとそのルートへ移動します。Maya標準のOpen/Recent FilesやQPEでシーンを開いた場合は、現在のタブをシーンのフォルダーへ移動します（場所をロックしたタブは既存の規則どおり新しいタブで移動）。保存・新規シーン・読込キャンセルでは閲覧中の場所を変更しません。

### 小さいMayaドックでの表示

Display settingsと開始フォルダー設定は **Tools（…）→ Navigation / scene** に常設しています。上部バーが収まらない幅では、Quick locations・New Scene・Save Scene Asもこのメニューに移します。FBXモード欄の幅も考慮し、パス・戻る／進む・左右サイドバーの切替を上部に残します。広げると省略した操作ボタンは戻ります。

ファイル一覧が狭い場合は場所名の見出しとViewの詳細表示名を省略し、検索欄を100px以上（DPI/UI倍率適用前）確保します。広げると元の表示へ戻り、検索条件は保持されます。さらに狭いドックでは全体の横スクロールを利用します。

QPEの内容の最小サイズがMayaのドック全体を押し広げないようにしています。ドックを小さくした場合は必要な方向にスクロールして操作できます。タイムスライダーより下の固定行だけに隣接したドックは、QPEを表示・復元する際に、サイズ変更できるタイムスライダーの上へ移動します。右・左ドックや、下側にサイズ変更できる別のドックがある配置、他エディターとの共有タブは維持します。手動で固定行の下へ移動して縮小できなくなった場合は、WindowメニューからQPEをもう一度表示してください。

ドックの監視対象はQPE本体と専用workspaceControlだけです。Maya本体・共有タブ・共有splitterのサイズ制約は変更しません。削除直後の再生成では旧監視と予約を解除し、新しい画面へ結び直します。回帰検証は `python tools/qpe_audit_runner.py <出力先> --maya 2027 --suites dock_lifetime dock_resize`（2022も指定可能）で実行できます。

狭幅・倍率・削除再生成・改名後のフォーカスの回帰は、同じランナーへ `--suites compact inspector_access recreation rename_focus shortcuts` を指定します。専用環境で起動し、終了コードとクラッシュダンプも判定します。Qtによる自動操作のため、実IMEや実ドラッグでの配置変更は別途実機で確認します。

終了時の回帰は `python tools/qpe_shutdown_runner.py <新しい出力先> --maya 2027 --repeat 3`（2022も指定可能）で実行します。専用prefsのMayaで8回ずつQPEを再生成し、通常終了と `os._exit(23)` によるDLL終了経路を別プロセスで検証します。後者は外部からの強制終了とは異なり、期待終了コード23を親ランナーで判定します。既存Mayaへ直接送信しないでください。独立したQt画面・アプリ全体のスタイルとフォントを保持し、QPEの描画が共有スタイルへのPython参照を残さないことも確認します。

行の背景・アイコンはQt標準デリゲートで描画し、列幅は部品自身の寸法から算出します。PySideから各ウィジェットの `style()` を取得すると共有 `QStyleSheetStyle` の参照が残り、終了時の破棄順によりクラッシュするため、行描画・列幅計算では取得しません。

### 操作別サイドバーの検証手順

検索画面は検索語を最初に選択し、Enterで検索します。詳細条件はMore search optionsにまとめ、結果の場所は検索範囲からの相対パスで表示します。全文はツールチップで確認できます。
一覧でCtrl+Shift+Nを押すと現在のフォルダーへ新規フォルダーを作成できます。中クリックでタブを閉じ、固定したタブは保護します。無効なアドレスを入力した場合はEscapeで現在地へ戻します。

ファイル一覧の幅が狭くなると、更新日時・サイズ・種類の順に補助列を省略し、名前を優先します。右詳細の長い名前は中間を省略して末尾を残します。
幅720論理px未満（DPI/UI倍率を適用）では右詳細を全幅のページに切り替えます。同じ右詳細ボタンでファイル一覧に戻り、幅を広げると通常のペイン配置に戻ります。
MayaのOpen後は対象ファイルの選択を維持し、Import／Referenceの完了は対象名と指定名前空間とともにQPE内へ表示します。Save Asの名前に付く拡張子は選択した形式に同期します。

コピー完了後のUndo履歴保存失敗は転送失敗とは分けて通知し、完了済みファイルを再試行対象にしません。一時的な共有違反は上限付きで再試行し、保存できない場合は専用Undoフォルダーに復旧用履歴を保持します。次の操作開始時に履歴を復旧できなければ、その操作を開始しません。
回帰検証は `tools/test_qpe_history_failure.py` と `tools/qpe_ui_review_fixes.py` にあります。後者の `main(output_dir, finished)` は専用Maya GUIランナーにも対応します。

`tools/qpe_ui_operations.py` は専用データでタブ切替、設定保持、コマンド対象、詳細の開閉、狭い幅での配置を検査し、Qt操作の画像連番を保存します。Maya GUI内では専用テストランナーから `main(output_dir, finished)` を呼びます。Windows実入力の確認とは区別してください。

起動時は保存タブの現在地を一度だけ読み込みます。非表示の左サイドバーは表示時に構築し、行の寸法計算ではShellアイコンを取得しません。`tools/qpe_startup_probe.py`は隔離した設定コピーで初回描画と起動処理を計測します。

`tools/qpe_ui_first_display.py <.maya-output内の専用出力先>`は、日本語名の専用ファイル1,000件を作り、QPE構築開始から一覧の先頭描画と全件反映までを分けて測ります。Python import・exe起動時間は含みません。Qtによるプログラム操作であり、OSのディスクキャッシュを消した測定ではありません。Mayaでは`tools/qpe_native_runner.py`の`--suites qpe_ui_first_display`から実行でき、ホスト起動直後の遅延処理が計測に含まれる場合があります。

フォルダー移動では訪問済み一覧の並べ替えを維持し、ルート変更で表示対象が変わるフォルダー行だけを再評価します。ディスクの再列挙・世代照合は省略しません。下段の補助列の自動幅は可視行から算出します。Windows単体版でも一覧作成時に全ファイルのShellアイコンを取得せず、可視行を最大2要求ずつワーカーで読み、GUIで適用します。サムネイル画像は遅れて届くShellアイコンで上書きしません。

全選択時は選択範囲を一度だけ展開し、フッターの合計容量は一覧の列挙済みメタデータから計算します。再列挙でサイズが変われば合計も更新します。新規行のサイズ・拡張子・更新日時はモデルへ挿入する前に揃え、行追加後の重複通知を減らします。可視アイコンの確認タイマーは取得完了後に休止し、スクロール・描画更新・再表示で再開します。

検索解除時の全行の表示照会はQt標準モデルへ任せ、サイズの単位付き文字列は値の更新時にだけ作ります。並べ替え・合計容量・アイコン更新判定には別途保持する数値を使い、名前・拡張子・日時もそれぞれ元の型で並べ替えます。サイドバーの開閉では最終幅が決まってからカラムを一度配置します。ファイル一覧の補助列は内容・可視行・文字サイズが変わったときだけ幅を測り、横幅だけの変更では名前列へ余白を配分します。狭幅で隠れた補助列を戻すときも再計算します。`tools/qpe_ui_search_panels.py`で検索、数値順、表示単位、スクロール・狭幅・文字サイズ変更後の列幅を検証します。

256件以上の更新一覧は、列挙後のGUI反映を最大512項目・約12msずつに分けます。先頭から表示し、残りの反映中も移動や選択を受け付けます。処理中は件数の横に`Loading…`を表示し、全件反映前に読込完了とは扱いません。移動・更新・終了で古い世代の反映を中止し、再訪では保持済みの行を再利用します。タブ読込中のクリック・キー入力・ホイールは保存状態の遅延復元より優先します。ディスク列挙自体は別スレッドで全件取得するため、遅いネットワークの初回列挙待ちは別途残ります。`tools/qpe_ui_progressive.py`で途中取消・世代逆転・選択・フィルター・終了を、`tools/qpe_ui_streaming_latency.py`で移動/戻る/タブの初期描画と完了時間を分けて検証します。

上段カラムの走査では、ファイルのサイズ・更新日時を取得しません。全件反映済みのタブへ戻った場合は、再列挙を待たずに保存された選択とスクロールを復元します。バックグラウンドで一覧を再確認し、削除された項目はその結果で取り除きます。未完成の段階表示はこの復元キャッシュとして扱いません。

右サイドバーの **File details** が閉じている間はプレビューや詳細情報を取得しません。開いた時点の最新の選択だけを読み込みます。Open／Import／Reference等の操作対象は、詳細欄の表示状態にかかわらず即座に更新します。`tools/qpe_ui_responsiveness.py` は専用データで選択・検索・サイドバー・スクロールのQt操作計測と回帰を行います。OS実入力やネットワーク待ち時間の保証とは区別してください。

作成・改名・シーンOpen後のファイル選択は、既に行があれば即時に行います。読込待ちの間に別の項目を選んだ場合や、新しい選択要求・階層移動があった場合は古い要求を破棄します。`tools/qpe_ui_navigation_latency.py`で、親子再訪・検索・数値ソート・外部更新・遅いアイコン取得・選択競合を専用データで検証できます。
