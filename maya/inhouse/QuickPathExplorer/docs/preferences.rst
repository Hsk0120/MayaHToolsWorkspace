設定
====

**ツール → オプション** を開きます。上部の **Aa** は同じ画面の「表示」を直接開きます。
用途別の5つのタブで設定し、保存で適用します。
文字・配色・列幅はその場でプレビューし、キャンセルやタイトルバーで閉じると元に戻ります。

全般
----

言語は日本語（JP）／English（EN）です。既定は日本語です。
保存後にQPEを開き直すと反映されます。
MayaではQPEを閉じ、ウィンドウ メニューから再表示してください。
ファイル名、パス、タグ、Mayaの表示言語は変更しません。

表示
----

.. list-table::
   :header-rows: 1
   :widths: 24 76

   * - 項目
     - 内容
   * - 配色（Windows版）
     - Windowsテーマへの追従、ライト、ダーク、クラシック ライトを選びます。Maya版はダークを使用します。
   * - サイズ
     - 最小10px相当から、11／12／14／16px相当のプリセットとカスタムを選びます。
   * - 文字サイズ
     - 基準文字を10〜24pxで設定します。実際の表示はDPIとUI倍率を反映します。
   * - UIの倍率
     - 75〜200％。文字も含めて調整します。MayaではホストのDPIを基準にします。
   * - 行の間隔
     - コンパクト／ゆったりを選びます。
   * - カラム幅
     - ウィンドウ幅に合わせる／フォルダー名に合わせるを切り替えます。
   * - 既定値に戻す
     - 表示設定を既定値へ戻してプレビューします。保存で確定します。

一覧では :kbd:`Ctrl++`／:kbd:`Ctrl+-` でも文字を拡大・縮小し、:kbd:`Ctrl+0` で既定へ戻せます。
文字入力欄では入力・編集が優先されます。

ファイル操作
------------

元に戻す履歴の保持日数は既定30日、履歴バックアップの上限は既定1024MiBです。
履歴画面で手動整理するときの目安です。設定しただけでファイルを自動削除しません。
Undoのための退避は容量を使うため、必要に応じて履歴画面で確認してください。

ショートカット
--------------

コマンド名またはキーで検索して割り当てます。
検索で隠れた行の編集も保持します。
通常のファイル操作に予約したキーとの競合は保存時に検査します。
カスタムキーはQPE内だけで有効です。入力欄やMayaの別ビューの入力を優先します。
標準キーは :doc:`shortcuts` を参照してください。

外部アプリケーション
--------------------

FFmpeg、Everything CLI、File Locksmith CLIの実行ファイルを指定します。
参照ボタンで選ぶかパスを入力し、クリアボタンで解除できます。
空欄では内蔵機能または自動検出を使います。Everything等の外部製品そのものを自動導入しません。

設定のバックアップ
------------------

**ツール → その他 → 設定のバックアップ** からJSONへ書き出し／読み込みします。
上書きの確認内容を確認してから読み込んでください。
言語や表示等の設定も対象です。ファイル操作の元データのバックアップとは別です。
