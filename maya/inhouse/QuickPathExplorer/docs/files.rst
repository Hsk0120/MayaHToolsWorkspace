ファイル操作と検索
==================

開く・名前を変える
------------------

ファイルをダブルクリックすると開きます。Windows版は関連付けアプリを起動します。
Maya版のma／mb／fbxは :doc:`maya` を参照してください。

一覧の :kbd:`F2` または :kbd:`Enter` は名前変更です。
編集中はEnterで確定、Escapeで中止します。長い名前は編集欄の中で横スクロールできます。

右クリックの使い分け
--------------------

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 場所
     - 主な操作
   * - ファイル／フォルダー
     - 開く、切り取り、コピー、名前の変更、削除、パスとしてコピー、プロパティ
   * - その他のオプションを表示
     - お気に入り、コピーの作成、一括改名、タグ・評価、ZIP、エクスプローラーで表示
   * - 一覧の背景
     - 更新、ファイル操作を元に戻す／やり直す、貼り付け、新規作成、ターミナル
   * - Maya（Maya版）
     - ファイルの読み込み、リファレンス

右クリックの対象はメニューを開いた時点で固定します。
選択外を右クリックしても既存の選択・プレビューを変更しません。
表示項目はフォルダー／ファイルや選択数で変わります。

コピー・移動・削除
------------------

コピー／移動先で名前が衝突する場合は確認します。
貼り付け先に同名ファイルがあるときは「ファイルを置き換える」が確認画面の既定です。
置き換え前のファイルはUndoで戻せます。
フォルダー結合はコピーに対応し、結合先だけにあるファイルを残します。
シンボリックリンクやジャンクションで開いたフォルダーの中でもコピー・移動できます。
Undo／Redoは、転送した時点の実際の場所を使います。転送の再開時にリンク先が変わっていると停止します。
削除はWindowsのごみ箱への移動です。OSの完了後に一覧と別タブを更新します。

QPEのファイルUndo／RedoはMayaシーンのUndoとは別です。
完了時は下部に「元に戻す」または「やり直し」と完了件数を表示します。
中断やエラーがあった場合も、その状態を併せて表示します。
**ツール → ファイル操作** の履歴から確認できます。
最新の操作から順に戻し、新しい操作を行うとRedoは失効します。
退避先や復元先に外部変更を検出した場合は上書きせず停止します。

転送を止める・再開する
----------------------

時間のかかるコピー・移動では、転送先と進行状況を別ウィンドウに表示します。
コピー後の内容確認中は「転送したファイルを確認しています…」と表示し、確認が終わるまで完了扱いにしません。
一時停止・再開・キャンセルは実行中の転送に適用します。
ジョブ／再試行の画面で実行中・待機中・完了した処理を確認します。
キューの停止は次のジョブの開始を止め、実行中の転送停止とは区別します。
コピー・移動・複製の保存済みジョブは、再起動後に対象を確認して明示的に再開します。

再開は項目単位です。途中のファイルは先頭からコピーし直します。
OSがI/O待ちのときは、中止要求がすぐに反映されない場合があります。
履歴保持の目安は :doc:`preferences` のファイル操作で設定します。

検索・整理
----------

**ツール → 検索と整理** から子フォルダー検索、重複ファイル、フォルダー比較、サイズ集計、
SHA-256、所在の診断を使えます。見つからない操作は :kbd:`Ctrl+Shift+P` のコマンド検索から探します。

検索には保存検索、名前やサイズ等の条件、本文検索を用意しています。
タグ・評価・コレクション、一括改名の下見、2番目のファイル一覧も利用できます。
Everything CLIを使う場合は :doc:`preferences` で実行ファイルを指定します。

ZIPとプレビュー
----------------

ZIPは作成、展開前の閲覧、選択した項目の展開に対応します。
20GiB／10万項目を上限とし、展開先からのパス逸脱、リンク、重複名を拒否します。

サムネイルは可視範囲から非同期に読み込みます。
メディアの静止プレビューに同梱デコーダーを使用し、通常の「開く」は関連付けアプリへ渡します。
プレビュー選択だけでMayaシーンを開きません。
