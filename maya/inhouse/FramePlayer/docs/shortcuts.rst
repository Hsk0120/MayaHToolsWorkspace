キー操作
========

Maya と同じキーは、Maya と同じ動きをします。

コマ送りと再生
--------------

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 動作
   * - → / ←(Alt + . / Alt + , も同じ)
     - 1コマ進む / 戻る。再生範囲の端では反対の端へ回り込む
   * - Shift + → / ←
     - 10コマ進む / 戻る
   * - Home / End
     - 再生範囲の最初 / 最後へ(Alt + Shift + V でも最初へ)
   * - Space / Alt + V
     - 再生 / 停止
   * - Esc
     - 再生を止める。フルスクリーン中は元のウィンドウに戻す(再生は続く)
   * - I / O
     - 再生範囲の最初 / 最後を、今のフレームにする
   * - K を押しながら映像の上を左ドラッグ
     - フレームを動かす(左右に 8 ピクセルごとに 1 コマ)。再生中はドラッグの間だけ止まる
   * - 映像の上で中ボタンドラッグ
     - フレームを動かす。比較中は、右の映像の上なら右のずらしを、左の映像の上なら左だけを動かす

表示
----

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 動作
   * - Ctrl + F / 映像のダブルクリック
     - フルスクリーンの切り替え(操作部はそのまま出る)
   * - 映像の上で右クリック
     - メニュー(再生/停止・フルスクリーン・色の情報・色の解釈)

ファイルと比較
--------------

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 動作
   * - Ctrl + O
     - 動画を開く
   * - Ctrl + Shift + O
     - 比較する2本目を開く
   * - [ / ]
     - 比較中、右のずらしを 1 コマ減らす / 増やす(Shift と一緒なら 10 コマ)

音声
----

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 動作
   * - M
     - 消音の切り替え
   * - ↑ / ↓
     - 音量を 5% 上げる / 下げる(消音中なら消音も解除する)

数字の欄
--------

フレーム番号や範囲の欄は、押すと番号を入力できます。Enter で確定、Esc で取り消します。ほかの所を押しても確定します。
