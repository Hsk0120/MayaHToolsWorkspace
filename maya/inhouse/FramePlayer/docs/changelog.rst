変更履歴
========

1.0.0
-----

最初の版です。

* 動画のコマ送り・再生。全コマの目次を作り、コマ番号を正確に決めます。可変フレームレートの動画にも対応します。
* Maya と同じ形のタイムスライダー・レンジスライダーとキー操作。
* GPU でのデコードと縮小、上限付きのキャッシュと先読み。Maya と同時に使うための省メモリ・省電力の動き。
* 2本の比較(同じコマ番号で左右に並べる、右だけをずらす)。
* 色の情報を読んだニュートラルな表示(HDR・10bit・色域の変換・手動の指定)。
* Windows のすべての動画のデコーダーと入れ物の組み合わせを確認。
* 連番画像(png・jpg・tif・bmp・gif・webp・heif・avif・jxl・jxr・exr)。OpenEXR は自前で読みます。
* Maya のタイムスライダーとの双方向の連携(相互認証付き)。FramePlayer だけを入れた人向けの連携スクリプト。
* セットアップ(ユーザー単位のインストール、拡張機能を確かめたうえでのファイルの関連付け)。
* 画面の文字は英語。
