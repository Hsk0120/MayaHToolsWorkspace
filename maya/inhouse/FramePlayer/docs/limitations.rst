制限
====

* Windows 専用です(Windows 10・11 の 64bit)。
* 逆再生・再生速度の変更・J/K/L の操作は、まだありません。
* キャッシュの上限を変える画面は、まだありません(レジストリで変えます。:doc:`settings`)。
* ProRes など、Windows にデコーダーが無い形式は開けません(:doc:`formats`)。
* 表示は画面の書き換えに合わせるので、画面の書き換えの回数(多くの画面で 60Hz)より多いコマは表示できません。
* 画面が消えている(省電力・ロック中)と、再生の表示も進みません。
* OpenEXR の深いデータ(deep)と、層の切り替えは未対応です(:doc:`sequences`)。
* ICC プロファイル・OCIO・LUT は使いません(:doc:`color`)。
* Windows 11 の新しい右クリックメニューの最初の段には「Open with FramePlayer」は出ません(「その他のオプションを確認」の中に出ます)。
* セットアップには署名がありません。インターネットからダウンロードすると、SmartScreen の警告が出ることがあります。
