概要
====

hedit とは
----------

hedit は Maya のスクリプトエディターの代わりに使える、Python / MEL 用のエディターです。
Maya 標準のスクリプトエディターにない次の機能を持ちます。

* 複数タブ・行番号・Dark+ 配色のコード欄
* 入力中の補完(``maya.cmds``\ 、読み込み済みのモジュール、ソース上の関数・クラス)
* 構文の静的解析、英語のスペルチェック(どちらも設定で切り替え)
* 検索・置換(大文字小文字、単語単位、正規表現)
* フォルダーを一覧する Explorer
* 未保存のタブも含めた、Maya 再起動後の自動復元
* 出力欄(種別ごとの色分け、表示モード切り替え、行番号、折り返し)

画面の構成
----------

.. code-block:: text

   ┌ メニュー: File / Edit / History / View / Command / Tabs ────────────┐
   │ ツールバー(開く・保存・消去・表示切り替え・実行・Explorer)        │
   ├──────────┬──────────────────────────────────────────────────┤
   │          │ 出力欄(Output)                                  │
   │ Explorer ├──────────────────────────────────────────────────┤
   │          │ コード欄(タブ)                                  │
   │          ├──────────────────────────────────────────────────┤
   │          │ 問題一覧(静的解析がオンのときだけ)              │
   └──────────┴──────────────────────────────────────────────────┘
   ステータス欄(補完の状態・検索の件数・言語 Python / MEL)

* 出力欄が上、コードのタブが下です。境界をドラッグして高さを変えられます。
* Explorer は左側のサイドバーで、View メニューまたは Ctrl+B で表示を切り替えます。
* 問題一覧は、静的解析(:ref:`pref-staticAnalysis`)がオンで、アクティブなタブが Python のときだけ、コード欄の下に出ます。

Maya 標準スクリプトエディターとの関係
-------------------------------------

* コードは Maya 標準の Python 実行経路で実行します。変数の名前空間は標準のスクリプトエディターと共有します。
* 実行結果・警告・エラーは Maya 共通の出力に流れるため、標準のスクリプトエディターにも表示されます。
  逆に、標準のスクリプトエディターや他のツールからの出力も hedit の出力欄に表示します。
* ``stdout`` / ``stderr`` の置き換えはしません。シーン操作の Undo は実行したコマンドに従い、hedit が Undo チャンクを追加することはありません。
* 標準のスクリプトエディターの全機能を複製するものではありません。

動作環境
--------

* Windows の Maya 2022(Python 3)/ 2024 / 2025 / 2026 / 2027 で、ビルド・単体テスト・standalone・GUI の確認をしています。
  Maya 2023 は確認していません。
* Maya のバージョンごとに別のバイナリ(``hedit.mll``)を使います。Qt は Maya 同梱の Qt を動的に使います(2022・2024 は Qt5、2025 以降は Qt6)。
* スペルチェックは Windows 標準の辞書を使うため Windows 専用です(:ref:`pref-spellCheck`)。
