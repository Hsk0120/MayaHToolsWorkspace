hlib for Maya
=============

hlib は Maya のノード・属性ラッパー、シーン操作、数学型、共通ユーティリティを
提供する内製 Python ライブラリです。

ノードや属性を Python オブジェクトとして扱い、Maya のスクリプトから
シーン操作やトランスフォームの計算を行えます。
各クラス・メソッドの使い方は、モジュールリファレンスマニュアルを参照してください。
