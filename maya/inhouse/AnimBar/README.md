# Anim Bar

タイムスライダーの上にドックする、アニメーション作業用のツールバーです。
処理は mlib だけで書き(`animBar.core`、Qt を使わない)、画面は PySide(`animBar.ui`)です。
アイコンは画像ファイルを使わず、`animBar/ui/icons.py` で描いています。

## 起動

- `maya/modules/AnimBar.mod` が有効なら、Maya GUI の起動後に自動でバーを表示します(前回閉じていれば表示しません)。
- HTools > animation > animBar、またはスクリプトの `import animBar; animBar.toggle()` で表示・非表示を切り替えます。
- 主な操作は runTimeCommand(カテゴリ `Custom Scripts.Anim Bar`)として登録するので、Hotkey Editor でキーを割り当てられます。

## 機能

| 区切り | ボタン | 内容 |
| --- | --- | --- |
| Tween | 前のキー・スライダー・後ろのキー・プリセット | 前後のキーの間の値でキーを打つ。スライダーの端を越えると行き過ぎ |
| Keys | モード・スライダー・左右の時刻・細かい足し引き | 選んだキーを、前後のキー・既定値・記録した時刻・反対側のコントロールへ近づける、直線から押し出す、イーズ、揺らす、前・後ろのキー・平均・既定値を中心に拡大・縮小する(Shift で平均から拡大・縮小、Ctrl で既定値へ近づける) |
| Tangents | auto〜plateau・flow・bounce | 接線型の設定。flow は前後のキーを結ぶ向き、bounce は山・谷を flat。右クリックで各カーブの最初・最後・全キーだけに設定 |
| Time | キーを前後へ・間を空ける/詰める・キーをそろえる・前後のキーへ・範囲・プレイブラスト | キーの時間の操作と再生範囲の保存・切替、プレイブラスト |
| Pose | リセット・ミラー・入替え・全体へ反映・コピー・貼付け | ポーズとアニメーション(右クリック)の左右反転・反対側の選択、変更を全キーへ反映(押して変えてもう一度押す)、アニメーションのコピー(別キャラクター・現在時刻へずらす・反転) |
| Space | 位置合わせ・スペース切替・仮のピボット・仮のコンストレイント | ワールドの位置を保つ操作。範囲を指定するとフレームごとにキーを打つ |
| View | モーショントレイル・細かい移動・タンブル・退避 | 表示の補助と、クラッシュに備えたアニメーションの退避(有効にした状態は次の起動でも保ち、新しい退避があれば戻すかを聞く) |
| Sets | 選択セットのボタン・作成 | 色付きの選択セット(クリックで選択、Shift で追加、Ctrl で除外)。書出し・読込み |

左右の対応は名前(`L_`/`R_`・`_L`/`_R`・`Left`/`Right` 等)で探します。反転するアトリビュートの既定は、左右のコントロールが `translateX`、中心のコントロールが `translateX`・`rotateY`・`rotateZ` で、ミラーの右クリックで変えられます。
ノードに `animBarMirrorInvert`(カンマ区切りの文字列)を足すと、そのノードで反転するアトリビュートを変えられます。

タイムスライダーで範囲を選ぶ(Shift+ドラッグの赤い範囲)と、Graph Editor でキーを選んでいないときの操作(キー変形・接線・
キーを前後へ・アニメーションのミラー・コピー・プレイブラスト)は、その範囲のキーを対象にします。
アニメーションレイヤー・pairBlend を介したアトリビュートは、Maya がキーを打つレイヤー(選んだ・優先するレイヤー)のカーブを編集します。
プレイブラストの音声・HUD・範囲・オーバースキャン・大きさはプレイブラストの右クリックの Settings で変えられます。

## aTools との違い

挙動は aTools を参考にしていますが、コードは流用していません。次の点は aTools と違います。

- アニメーションレイヤーでは、キーの値はそのレイヤーの値(下のレイヤーとの差)として扱います。Keys の Mirror モードの
  目標は反対側の最終的な値なので、差分のレイヤーでは目標がずれます。
- タイムスライダーの範囲の読取りは GUI でだけ働きます(バッチ・mayapy では範囲を選んでいない扱い)。
